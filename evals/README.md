# 离线发版回归评测集 (Offline Release Eval Benchmark)

本目录专用于 **Skill 重大版本迭代时的离线回归评测**（修改 `SKILL.md`、检索算法、通道规则或风格母版后的对比验收），**不侵入日常单次出图生产流程**（日常出图无需填写评测日志）。

## 评测定位与反主观陷阱原则

当只有单一评测者（`n = 1`）时，“选了哪套”很容易混入个人当天的口味偏好，无法作为统计学胜率。因此本评测集强制采用**“客观结构层 + 主观偏好层”双栏评分**：

1. **客观结构层（判断 Skill 是否合格或是否把模型拽僵）**：
   - **事实与素材守卫**：有无虚构产品结构、参数、认证或错标标配/选配；
   - **通道与体裁路由**：是否选对了 `output-qa-gate.md` 通道（如长参数表走通道 3、暗场新光影走通道 1 无字重绘而非硬抠图、展会邀请函不强塞商品抠图）；
   - **客观红线通过度**：`QA-1`–`QA-5` 及 `scripts/qa_check.py` 机检结果；
   - **反模板化结构检查（对比无 Skill 基线）**：相比不读本技能的干净基线，带技能方案是否出现“硬套网格、强塞参数卡片、生硬复刻母版配色导致失去任务自然感”的结构性僵化？
2. **主观偏好层（诚实标记，不直接用于判 Skill 死刑）**：
   - 仅记录个人风格喜好（如冷暖调性、审美偏爱）。**只有当“无技能基线赢在可复用的结构动作，且带技能方案暴露了明确的规则副作用”时，才反拆改进规则或补充 `co_dissected_teardown`。**

## 单人评测时的低成本多视角初筛

若仅 1 人验收全部 7 道固定题，可在离线跑完样本后，让模型分别扮演两个视角做初筛并写出具体理由，人只在有分歧或暴露结构僵化的题目上拍板：
- **视角 A（目标买家 / 采购决策者）**：3 秒内能不能看懂卖什么、尺寸/配件/行动入口清不清楚、有没有被无关元素干扰？
- **视角 B（资深商业视觉总监）**：构图和光影是否贴合载体与观看距离、有没有廉价模板味或刻意堆砌？
