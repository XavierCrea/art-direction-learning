# 出图分流与审美验收硬门禁 (Execution Routing & Output QA Gate)

本文件是 `art-direction-learning` 从“上游策划”通往“下游成图”的**强制质量闸门**，用于防止上游美术方案在落地阶段翻车（如硬抠图贴纸感、光影割裂、代码硬画成程序员 PPT 流程图、首图未验收就盲目批量出图）。

---

## 一、 出图前：三层架构与光影匹配分流硬规则

在决定把一张海报交给 AI 生图、Python/SVG 代码渲染还是混合制作前，**必须按以下分流表执行，不得越界**：

| 画面类型与素材条件 | 强制渲染路线 | 三层职责分工 | 明确禁区 |
| :--- | :--- | :--- | :--- |
| **A. 纯平面 / 几何构成 / 远距纯色大牌 / 参数表 / 二维码**（无复杂实物光影融合需求） | **通道 2：代码级精确渲染**（Python PIL / SVG） | 代码直出模数网格、品牌 HEX 色场、锋利小字与 `zxingcpp` 校验真二维码 | 禁止把这类强文字/网格/二维码页面交给纯 AI 生图导致拼写乱码或扫码失败 |
| **B. 含实体产品，且原图与目标场景光影一致**（如白底均匀棚拍图 $\rightarrow$ 浅色/纸白功能网格页） | **三层混合管线（模式 1：底图 + 抠图合成）** | `Layer 1` AI 生成纯净无字场景底图并预留文字呼吸区 $\rightarrow$ `Layer 2` 高精前景抠图 + 自然接触阴影 $\rightarrow$ `Layer 3` SVG/代码压字与引线 | **严禁**抠图脚本失败后改用手工估算多边形坐标硬切；抠图出现灰边锯齿必须停下换方案 |
| **C. 含实体产品，且原图与目标场景光影反差大**（如自然光办公桌实拍 $\rightarrow$ 暗场影棚/户外实景海报） | **三层混合管线（模式 2：AI 统一光影重构 + 局部贴回）** | `Layer 1` **AI 生图模型**以产品实拍图为身份参考（参考图提前压至 `~1000px / 150 KB` 以保速），统一重构产品金属反光、轮廓光、台面反射与整体光影氛围 $\rightarrow$ `Layer 2` 确定性脚本仅对 AI 易糊的**铭牌、Logo、二维码、关键丝印**做局部羽化贴回（`patch`） $\rightarrow$ `Layer 3` 矢量/代码精准压字或微调文案 | **严禁**用代码写纯色渐变背景再把自然光实拍图直接抠出来硬贴（必然产生廉价“贴纸感”）；**严禁**用代码硬画复杂 3D 光路、大量小方框和发光特效替代生图光影 |
| **D. 严禁 AI 伪造的证据类画面**（车间实拍、真机示波器、证书原件、真实线束全家福） | **通道 4：实拍与美工执行单** | 使用真实照片或输出去形容词补拍指令单 | 严禁 AI 编造虚假内部结构、认证证书或实测波形图 |

### 视觉锚点读取顺序（出图前必查）
1. 若本轮已选定 `library/styles/<style-id>.md` 实证风格母版，**先检查 `library/style-refs/<style-id>/local/` 是否存在精选标杆参考图**；
2. 存在时，精选 **1–2 张最匹配本页构图骨架的锚点图**连同产品身份参考图一并传入 Layer 1 生图模型，锁死光影、材质与留白调性；
3. 不存在时，严格依据已选风格母版（或本轮用户确认的视觉参考）与 [poster-patterns.md](poster-patterns.md) 的面积预算与禁用令编写 Prompt。

## 二、 出图后：5 条审美与构图一票否决红线

**审美与融合缺陷不再降级为“可选建议”。** 成图生成后，执行者必须实际打开查看成图，逐项核对以下 5 条红线——**命中任意一条即判定不合格，阻止作为成品交付，必须切换有依据的方案返工**：

| 序号 | 一票否决红线 | 典型失败症状（见到即打回） | 强制修正动作 |
| :--- | :--- | :--- | :--- |
| **QA-1** | **贴纸感与边缘缺陷** | 抠图边缘发白/灰边锯齿、手工切边切掉结构、主体漂浮在背景上无真实接触阴影或倒影 | 立即废弃硬抠方案；光影不匹配时切换至“模式 2：AI 统一光影重构 + 铭牌局部贴回” |
| **QA-2** | **光影与色温割裂** | 暗场深蓝背景上贴着发灰的漫射自然光产品；环境冷光但产品暖黄；台面材质与产品反光毫无物理关联 | 统一交由 Layer 1 生图模型重建一致的主光源方向、边缘轮廓光与台面材质反射 |
| **QA-3** | **流程图 / 程序员 PPT 感** | 满屏粗边框矩形盒、高饱和发光描边、20+ 格死板表格卡片喧宾夺主、生硬粗折线穿插遮挡硬件 | 砍掉冗余容器边框与次要元素；遵循 [poster-patterns.md](poster-patterns.md) 的视觉预算（1 主焦点 + 最多 1 组克制辅助证据） |
| **QA-4** | **3 秒眯眼测试失焦** | 眯眼看成图时视线散落在 4–6 处同等强度的块面上，第一眼分不清主角是产品、面板、放大窗还是底部大徽章 | 放大唯一主角占比（`≥ 38%`），将其余元素降明度/去框/退居次级，确保 3 秒内视线只落 1 个锚点 |
| **QA-5** | **硬件事实、留白或可读性失守** | 光路/引线指错物理端口、原厂铭牌/丝印糊成乱码、标题贴顶窒息无留白、手机 `375px` 宽下关键小字糊成蚊子字 | 修正端口落点、对铭牌/丝印做原图 `patch` 贴回、清理顶部留白呼吸带并拉大移动端关键字号 |

## 三、 首图（代表图）先审后扩闸门

当任务包含 **2 张及以上的系列海报或详情页套图** 时，强制执行“首图闸门”：

1. **只先出第 1 张最具代表性的海报**（优先选含核心产品主体与光影难点的那一屏）；
2. 执行者先对照上方 **QA-1 至 QA-5** 自行核验，自检不过直接内部返工，**禁止把明显带硬伤的初稿硬往后续页面复制**；
3. 第 1 张代表图自检通过后，**必须暂停并展示给用户确认审美调性、光影美化程度与构图节奏**；
4. 只有获得用户对第 1 张代表图的明确认可后，才允许以该代表图为风格基准，批量生成同套其余页面（确保全套光影、台面、字阶与留白 100% 连贯）。
