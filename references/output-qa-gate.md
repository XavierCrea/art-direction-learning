# 出图分流与客观验收硬门禁 (Execution Routing & Output QA Gate)

本文件是 `art-direction-learning` 从“上游策划”通往“下游成图”的**质量闸门**，用于根据素材条件分流执行路线，并在成图后基于**客观错误标准**（读者会不会**看错什么、漏掉什么、做不成什么**，以及是否存在物理合成硬伤）把关，防止未验收的带病初稿批量扩散。

---

## 一、 出图前：三层架构与光影匹配分流硬规则

在决定把一张海报交给 AI 生图、Python/SVG 代码渲染还是混合制作前，**必须按以下分流表执行，不得越界**：

| 画面类型与素材条件 | 强制渲染路线 | 三层职责分工 | 明确禁区 |
| :--- | :--- | :--- | :--- |
| **A. 纯平面 / 几何构成 / 远距纯色大牌 / 参数表 / 二维码**（无复杂实物光影融合需求） | **通道 2：代码级精确渲染**（Python PIL / SVG） | 代码直出模数网格、品牌 HEX 色场、锋利小字与 `zxingcpp` 校验真二维码 | 禁止把这类强文字/网格/二维码页面交给纯 AI 生图导致拼写乱码或扫码失败 |
| **B. 含实体产品，且原图与目标场景光影一致**（如白底均匀棚拍图 $\rightarrow$ 浅色/纸白功能网格页） | **三层混合管线（模式 1：底图 + 抠图合成）** | `Layer 1` AI 生成纯净无字场景底图并预留文字区 $\rightarrow$ `Layer 2` 高精前景抠图 + 自然接触阴影 $\rightarrow$ `Layer 3` SVG/代码压字与标注 | **严禁**抠图脚本失败后改用手工估算多边形坐标硬切；抠图出现灰边锯齿必须停下换方案 |
| **C. 含实体产品，且原图与目标场景光影反差大**（如自然光办公桌实拍 $\rightarrow$ 暗场影棚/户外实景海报） | **三层混合管线（模式 2：AI 统一光影重构 + 局部贴回）** | `Layer 1` **AI 生图模型**以产品实拍图为身份参考（参考图提前压至 `~1000px / 150 KB` 以保速），统一重构产品反光、轮廓光、台面反射与整体光影氛围 $\rightarrow$ `Layer 2` 确定性脚本仅对 AI 易糊的**关键型号铭牌、Logo、二维码、关键丝印**做局部羽化贴回（`patch`） $\rightarrow$ `Layer 3` 矢量/代码精准压字或微调文案 | **严禁**用代码写纯色渐变背景再把自然光实拍图直接抠出来硬贴（必然产生廉价“贴纸感”）；**严禁**用代码硬画复杂 3D 光效替代自然光影 |
| **D. 严禁 AI 伪造的证据类画面**（车间实拍、真机示波器、证书原件、真实线束全家福） | **通道 4：实拍与美工执行单** | 使用真实照片或输出去形容词补拍指令单 | 严禁 AI 编造虚假内部结构、认证证书或实测波形图 |

### 视觉锚点读取顺序（出图前必查）
1. 若本轮已选定 `library/styles/<style-id>.md` 实证风格母版，**先检查 `library/style-refs/<style-id>/local/` 是否存在精选标杆参考图**；
2. 存在时，精选 **1–2 张最契合本轮传播目的与素材条件的锚点图**连同产品身份参考图一并传入 Layer 1 生图模型，稳住光影与材质调性；
3. 不存在时，依据已选风格母版（或本轮用户提供的实拍素材/视觉参考）与 [poster-patterns.md](poster-patterns.md) 编写 Prompt。

## 二、 出图后：5 条客观验收一票否决红线

> **退稿准绳**：只有能够指出**客观合成硬伤**，或读者会**看错什么、漏掉什么、做不成什么**时才触发硬退稿；纯主观的“换种排法更好看”留给方案比选与风格母版判断，不作为硬红线误杀好方案。

成图生成后，执行者必须实际打开查看成图，逐项核对以下 5 条红线——**命中任意一条即判定不合格，阻止作为成品交付，必须返工修正**：

| 序号 | 一票否决红线 | 客观失败症状（见到即退回） | 强制修正动作 |
| :--- | :--- | :--- | :--- |
| **QA-1** | **合成边缘与物理融合缺陷** | 抠图边缘发白/灰边锯齿、手工硬切切残产品识别特征、主体漂浮在台面/地面上无合理接触阴影或倒影 | 立即废弃硬抠方案；光影不匹配时切换至“模式 2：AI 统一光影重构 + 关键识别区局部贴回” |
| **QA-2** | **光影与色温物理穿帮** | 产品与背景主光源方向、色温或反光明显矛盾（如冷暗场景贴着发灰的漫射自然光硬抠图），产生肉眼可见的“贴纸割裂感” | 交由 Layer 1 生图模型统一重建主光源方向、轮廓光与台面/环境材质反射 |
| **QA-3** | **事实、指向与行动闭环错误（防看错 / 做不成）** | 引线指错物理部位；作为识别依据的型号铭牌/Logo/丝印糊成乱码（背景非关键小字自然虚焦除外）；选配附件混作标配；画面内参数/日期/口径矛盾或遗留占位符；**二维码在最终发布尺寸下无法实扫，或扫码跳转页面与画面文案承诺不符** | 修正标注落点、对关键铭牌做原图 `patch` 贴回、清理冲突/占位符，并在终版尺寸下实扫验证二维码与目标落地页 |
| **QA-4** | **关键信息可读性与安全区失守（防漏掉 / 做不成）** | 完成当前任务所需的关键信息或产品识别特征被裁切/遮挡（艺术性非关键裁切除外）；文字在**实际发布位置与观看距离**下糊成不可读小字（如手机 `375px` 样例看不清或 9:16 竖屏压入平台 UI 安全区 `M-033`）；文字与背景对比度不足导致融边 | 移入安全区、调整裁切与字号层级、补足文字底图明度对比，按实际发布终端重新验真 |
| **QA-5** | **主要意图被埋没或背离本轮风格契约** | 核心传播意图与必要行动入口被无关元素淹没导致读者“做不成”（如邀请到场却把展位号藏成极小字）；或成图严重背离本轮选定的风格母版与传播目的（如极简母版下泛滥套框堆砌成杂乱表格） | 抬升核心意图与行动入口的视觉优先级，并严格对齐本轮选定的风格母版与素材条件重构，不硬套固定主角占比或单一焦点教条 |

## 三、 首图（代表图）先审后扩闸门

当任务包含 **2 张及以上的系列海报或详情页套图** 时，强制执行“首图闸门”：

1. **只先出第 1 张最具代表性的海报**（优先选含核心产品主体与光影难点的那一屏）；
2. 执行者先对照上方 **QA-1 至 QA-5** 自行核验，自检不过直接内部返工，**禁止把明显带硬伤的初稿硬往后续页面复制**；
3. 第 1 张代表图自检通过后，**必须暂停并展示给用户确认审美调性、光影美化程度与构图节奏**；
4. 只有获得用户对第 1 张代表图的明确认可后，才允许以该代表图为风格基准，批量生成同套其余页面（确保全套光影、台面、字阶与视觉语言连贯一致）。
