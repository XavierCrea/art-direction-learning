# 出图分流与客观验收硬门禁 (Execution Routing & Output QA Gate)

本文件是 `art-direction-learning` **下游执行通道（通道 0–4）与客观验收红线（`QA-1`–`QA-5`）的唯一权威定义源**（Single Source of Truth）：先按成片光影与证据需求选定最保真、最省工的制作路线，再在构图前置自检与出图后验收中统一基于**客观错误标准**（能否指出读者会**看错什么、漏掉什么、做不成什么**，或写实作品存在客观合成穿帮）把关。

---

## 一、 下游执行通道分流表（唯一编号体系：通道 0 – 通道 4）

在定画面阶段即按**成片需要什么光影、版式与证据**直接锁死制作路线，避免先做一轮抠图、发现受光与接触阴影接不上再返工：

| 通道编号 | 成片需求与素材前提 | 职责分工与保真要点 | 明确禁区 |
| :--- | :--- | :--- | :--- |
| **通道 0 · 原片直排** | 原片光影与构图已符合目标（官方场馆照、完整棚拍图、现成高质量实景大片） | 保留原片真实光影、建筑结构或产品质感，直接完成裁切、必要调色与矢量/代码精准压字 | 严禁为了走流程而用 AI 重画本来就清晰准确的原片 |
| **通道 1 · AI 生图 / 改图与无字主视觉重绘** | 需要新场景、新光向、暗场或新的接触阴影（如自然光桌面实拍 $\rightarrow$ 暗场影棚、户外实景或氛围海报） | 含实体产品时，定画面阶段直接走**「参考实拍整图重绘无字主视觉 + 矢量排字」**：以实拍作外形与结构参考，一次性生成统一光影与接触阴影的无字主视觉（按版式预留干净留白，禁止 AI 在底图出字），再叠矢量文字与标注；核对端口/比例不失真，仅对画糊的关键铭牌/Logo 用原片高清母图做局部 `patch` 贴回（无可用生图工具或零容错时改换浅底或转通道 4） | 严禁先抠图或用代码调暗硬贴进暗场/实景底图冒充写实大片；严禁未核对端口与比例就把 AI 重绘硬件当实物交付 |
| **通道 2A · 纯平面代码级精确渲染** | 纯平面 / 几何构成 / 参数表 / 强网格 / 含二维码页面（无实物光影合成需求） | Python PIL / SVG 代码直出模数网格、精确品牌 HEX 色场、清晰小字与终版尺寸实扫可用的真二维码 | 严禁把密排文字、严格规格表或二维码交给纯 AI 生图导致乱码或扫码失败 |
| **通道 2B · 混合管线（平面底图 + 抠图 + 矢量排字）** | 需要透明素材，或产品与纯色/浅灰平面底图光影本就匹配 | 仅限光线均匀、无暗场反差或复杂实景透视的素材：干净纯色/浅灰网格底 $\rightarrow$ 高精前景抠图与自然接触阴影 $\rightarrow$ 矢量精准压字 | 严禁把“AI 生成的空暗场/空实景底图 + 本地实拍抠图”硬拼在一起；严禁抠图失败后用粗略多边形硬切残缺边缘 |
| **通道 3 · 响应式网页 / 交互组件代码** | 店铺装修、着陆页、可交互选型表、单栏语义分组斑马纹参数表（`M-005`/`M-020`–`M-023`）与纵向展开吸顶目录（`M-006`） | 直接交付 HTML / CSS / React 响应式代码，保证文字可检索、多端自适应与交互可点击 | 严禁将长参数表、导航目录或可交互选型模块整页切死成大图 |
| **通道 4 · 原片证据 / 摄影与美工执行单** | 接口定义、尺寸标尺、标配全家福（`M-003`）、车间实拍、真机示波器、认证原件等零造假证据图 | 直接使用真实原片、准确工程图，或输出去形容词的补拍/排版执行单；版面底色顺着原片光影选 | 严禁 AI 重绘改变结构、端口数，或编造虚假内部构造、认证证书与实测波形 |

> **工具限额备选提示**：仅当所用 AI 生图接口存在明确体积上限或超时风险时，可对参考图**生成压缩副本**（如约 `1000px / 150 KB`）传入模型，**严禁覆盖或损坏原始高清母图**，且铭牌/丝印贴回（`patch`）始终取自原图。

## 二、 出图前：视觉参考三级借用与缺图降级规范

调用 `library/styles/<style-id>.md` 时，先按本次借用层级检查 `library/style-refs/<style-id>/` 的可用资产（`library.py get <style-id>` 会返回 `anchor_tier`）：

| 借用层级 | 目标 | 所需资产 | 缺本地锚点图时的降级动作 |
| :--- | :--- | :--- | :--- |
| **L1 · 整体复刻参考气质** | 完整还原某套母版的光影、质感与套系节奏 | `local/` 下至少 **2 张**核心本地锚点图（`full_local_anchors`） | 若 `local/` 为空（例如新机器克隆），自动降级为 **L2/L3**，参考随包分发的零版权可视化参考卡 `descriptor.svg` 与文字规范，并在交付说明中显式标注**“文字/示意图级参考（本地无原图锚点）”** |
| **L2 · 原子手法借用** | 仅借单一手法（如纸张侧光、句首加黑、斜切分栏），保留客户自有品牌色 | 1 张对应本地锚点图，或随包分发的 `descriptor.svg`（`descriptor_only`） | 直接依据 `descriptor.svg` + 风格卡文字规则执行，无需强补第三方原图 |
| **L3 · 纯数值与版式规范** | 仅参考色阶、字阶、留白区间与网格结构 | `styles/<id>.md` + `descriptor.svg` | 零依赖，直接可用 |

> 风格参考与现有实拍素材或客户品牌规范冲突时，始终以**用户明确指定的品牌规范**和**真实素材客观条件**优先。

## 三、 客观验收五条一票否决红线（`QA-1` – `QA-5`）

> **退稿唯一准绳**：能否明确指出**写实作品的客观合成缺陷**，或读者会**看错什么、漏掉什么、做不成什么**。若只能说“我觉得另一种排法更好看”，留给审美与方案比选，不作硬红线退稿。
>
> **构图前置与出图后共用同一套编号**：构图与分镜阶段即应提前规避 **`QA-3`、`QA-4`、`QA-5`**（`poster-patterns.md` 直接对齐本表，不再另起编号）；成图完成后执行全量 **`QA-1` – `QA-5`** 核验。

### 确定性机检辅助（`scripts/qa_check.py`）
成图后可先运行轻量机检脚本校验客观技术指标，再由执行者（或高成本终版交付时的独立视觉复核子代理）实际开图完成全量核验：
```bash
python3 scripts/qa_check.py <成图路径> --expected-ratio 9:16 --check-qr --publish-width 375 --expected-url "https://..." --safe-zone-overlay out_safezone.svg
```
- 脚本自动核验**尺寸与画幅比例**、**发布尺寸缩放后的二维码实扫与跳转 URL 一致性**（需 `zxingcpp`/`pyzbar`/`cv2` 之一，缺失时会显式报告未跳过原因，绝不假通过），并生成 **9:16 平台安全区叠图预览**供肉眼复核；可选 `--brand-hex` 仅作纯色/矢量区域采样参考，不作写实照片硬退稿依据。

| 编号 | 一票否决红线 | 客观失败症状（见到即退回） | 强制修正动作 |
| :--- | :--- | :--- | :--- |
| **QA-1** | **合成边缘与物理融合缺陷（按创作意图评审）** | **写实作品**中出现抠图白边/灰边锯齿、误切产品识别特征、主体无合理接触阴影/倒影；*（注：刻意设计的剪纸、拼贴、手账等风格中，纸边与投影属于创作语言，按其创作意图评审，不误杀）* | 写实作品立即返工边缘与接触阴影，或切换更匹配的背景/补拍/通道 1 重绘路线 |
| **QA-2** | **光影、色温或硬件结构穿帮** | **写实作品**中产品与环境光源方向、色温、反射明显矛盾；或经 AI 重构后的真实硬件出现**端口数量错乱、散热孔/外形比例失真** | 统一光源与调色，或放弃 AI 重构改走通道 0 / 通道 2B / 通道 4，确保硬件物理结构准确 |
| **QA-3** | **事实、指向与行动闭环错误（防看错 / 做不成）** | 引线指错物理部位；作为识别依据的型号铭牌/Logo/丝印糊成乱码（背景非关键小字允许自然虚焦）；选配附件混作标配（`M-003`）；画面内参数/日期/价格口径矛盾或遗留占位符；**二维码在最终发布尺寸下无法实扫，或扫码跳转页面与画面文案承诺不符** | 修正标注落点、用原图做关键铭牌 `patch`、清理冲突/占位符，并在终版发布尺寸下实扫验证跳转目标页 |
| **QA-4** | **关键信息可读性与安全区失守（防漏掉 / 做不成）** | 完成当前任务所需的关键信息或识别特征被裁切/遮挡（不禁止非关键部位的艺术性裁切）；文字在**实际发布位置、观看距离与平台遮挡条件**下不可读（如手机 `375px` 预览样例糊字、9:16 竖屏压入平台 UI 安全区 `M-033`、字底对比度不足融边） | 调整裁切、安全区与字阶对比度，按实际发布终端重新验真 |
| **QA-5** | **主要意图被埋没或违背用户指定的品牌规范** | 核心传播意图与必要行动入口被无关元素淹没导致读者“做不成”（如邀请到场却把展位号藏成极小字）；或违背**用户明确指定的品牌规范**（如指定色值、禁用词、合规要求）。*（注：模型自行挑选的参考风格仅作设计建议，不得以此作为硬退稿依据）* | 抬升核心意图与必要行动入口的优先级，对齐用户明确指定的品牌规范 |

## 四、 代表图确认机制（跟着“有没有新的设计决定”走）

是否先出 1 张代表图暂停确认，**不设固定张数门槛**，取决于方向是否已定、选错是否会造成整批返工：

1. **何时先审代表图**：当制作**同风格套图、视觉方向尚未定稿、选错后会造成整批返工**时（例如 2 张昂贵的新创意大片，或 5 张尚未定调的系列详情页），先产出第 1 张最具代表性的成图，自检通过 `QA-1`–`QA-5` 后展示给用户确认，获准后再批量推进其余页面；
2. **何时直接整批交付**：
   - 用户明确要求**“同时给 2–3 个不同方向一起比较”** $\rightarrow$ 并行出齐各方向方案，供一次性比选；
   - **主视觉与样式已经定稿**，或用户明确要求**一次性出齐**（例如 10 张已定稿的尺寸变体、或同版 3 种语言版本） $\rightarrow$ 逐张完成 QA 自检后整批交付，不机械中途卡停；
   - **同版多语言 / 改尺寸变体的自检重点**：自动聚焦于**断行是否合理、字号是否依然可读、必要信息是否完整、以及对应语言落地页二维码是否跳转正确**。
