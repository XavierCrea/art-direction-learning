# 海报与套系构图骨架库 (Poster & Series Composition Patterns)

本指南提供一组可复用的**构图参考骨架**，并与 `library/styles/` 中的风格母版相互解耦。实际创作时，**根据传播目的、现有素材、品牌要求和观看场景，选用、组合或调整骨架与风格母版**——例如手里只有一张极具说服力的官方场馆照或实景大片时，可以直接从该素材出发设计，不必为了套用 `P-01`–`P-06` 给它硬配一项产品卖点。

---

## 一、 全局客观交付硬红线（全骨架通用 · 不干涉主观审美）

> **退稿唯一准绳**：能否明确指出读者会**看错什么、漏掉什么，或做不成什么**。如果只能说“我觉得另一种排法更好”，则交由案例库、风格母版与审美判断，不作为硬红线拦截。

以下 4 条只限制跨行业、跨风格的**客观硬错误**；具体的留白比例、焦点数量、容器与字阶样式，根据传播目的、现有素材、品牌要求和观看场景灵活选用、组合或调整：

1. **事实与指向准确（防看错）**：
   - 标注引线的落点必须与真实物理部位或规格严格对应；严禁虚构产品结构、测试数据，或将选配附件混作标配（`M-003`）。
   - **识别信息忠实还原**：作为识别依据的品牌 Logo、型号铭牌与关键丝印必须准确可辨，不得糊成乱码（背景器件上的非关键小字允许自然虚焦）。
   - **二维码终版实扫闭环**：留足静区，不仅须在**最终发布尺寸下实扫可识别**，还必须核对**跳转页面与画面文案承诺一致**（例如邀请函写“扫码预约”，扫出却是公司首页，即使码能识别也须退回）。
2. **完成任务所需信息的可读性与安全区（防漏掉 / 做不成）**：
   - 保护对象为**“完成当前传播任务所需的关键信息与识别特征”**——不禁止艺术性裁切（产品特写可裁掉半个机身，人物可走出画框），真正禁止的是裁切或遮挡导致**认错产品、漏掉时间/地点/关键条件，或行动按钮被遮挡**。
   - **按实际发布位置与观看场景验收**：移动端详情/社媒图可用 **`375px` 屏宽**作预览样例，9:16 竖屏须避让平台 UI 安全区（`M-033`），线下户外/展会物料须满足对应视距下的清晰可读，且文字与底图保持明确明度对比。
3. **信息自洽与成品完整性（防看错 / 穿帮）**：
   - 同一画面内不得出现互相矛盾的参数、日期、价格或口径冲突；严禁成品遗留未替换的占位文本、草稿标号或错乱字符。
   - *编辑优化建议（非硬退稿红线）*：精简无信息增量的冗余前缀与重复信息可参考 `M-020`（标签取舍）与 `M-011`（相关信息分组）；但凡具备功能区分价值的标签或双处复用（如电话与 WhatsApp 号码格式相同时用标签区分、展位号在主画面与可单独保存的票根上各出现一次），均应保留，不得机械删除。
4. **主要意图清楚，必要行动可完成（防漏掉 / 做不成）**：
   - 同一画面可以承载多个相互支持的目标（例如展会邀请函可同时激发兴趣、传达日期、标出展位并引导预约），不硬性限制“每屏只许一种任务”。
   - 真正必须退回的是**核心意图被埋没或必要行动无法完成**——例如明明邀请客户到场，展位号却藏在手机上读不清的小字里，或核心行动入口被无关元素淹没导致读者找不到下一步怎么操作。

## 二、 6 套可组合参考构图骨架（按目的与素材灵活选用/调整）

> 以下骨架及面积比例均为常见实战参考基准，用于避免“把无关模块无序堆砌在同一屏”；当优质实拍素材或特定传播目标需要突破默认切分时，可在守住上方 4 条客观红线的前提下自由组合或调整。

### 骨架 P-01：单品剧场微距骨架 (`hero-studio-macro`)
- **适用卖点**：旗舰外观、核心工艺、金属/皮革/织物材质质感、品牌首屏定调。
- **参考面积切分**：标题与留白区 `22%–28%`｜中部单品主视觉 `45%–55%`｜底部留白或简短注脚 `15%–20%`。
- **构图要点**：以单品主体 + 主副标题为视觉中心，克制使用引线与多卡片，让材质、光影与比例承担第一印象。
- **推荐渲染路线**：三层管线——Layer 1（AI 统一影棚光影重构或纯影棚底图）+ Layer 2（原厂铭牌/Logo 局部保真）+ Layer 3（矢量压字）。

### 骨架 P-02：结构证据与局部标注骨架 (`evidence-callout`)
- **适用卖点**：结构亮点、接口/功能位点、内部材质或防护工艺拆解（对应 `M-002`）。
- **参考面积切分**：标题区 `18%–22%`｜核心产品大视角主体 `42%–50%`｜单一精简证据区（如 1 组参数摘要或 1 处局部细节放大）`15%–20%`｜底部背书条 `8%–10%`。
- **构图要点**：引线数量保持克制（建议 `≤ 3–4` 条），起点 100% 准确落在对应物理部位上，线条与标注不遮挡作为识别依据的型号或关键细节。
- **推荐渲染路线**：三层管线——原图与目标场景光影反差大时，走 Layer 1（AI 统一光影与材质氛围）+ Layer 2（铭牌/二维码/关键标识无损 `patch`）+ Layer 3（精确矢量文字与标注线）。

### 骨架 P-03：主视窗 + 多栏场景证据骨架 (`hero-plus-scenario-grid`)
- **适用卖点**：一项核心能力覆盖 2–3 种典型使用场景或人群工况（如多模式切换、多材质适配、全天候防护，对应 `M-016` 模数网格）。
- **参考面积切分**：标题区 `18%–20%`｜上半部核心产品或关键部位主视窗 `38%–44%`｜下半部 2 栏或 3 栏等宽等高场景证据卡 `32%–36%`。
- **构图要点**：下半部卡片建议 2–3 栏，每卡保持统一信息结构（同色温小图 + 编号/短标题 + 1 句短说明），顶底严格对齐。
- **推荐渲染路线**：三层管线——Layer 1 统一生成上半部主体与下半部同色温场景图，Layer 3 精准排布等宽网格与清晰文案。

### 骨架 P-04：核心指标 / 极化对比骨架 (`metric-or-comparison`)
- **适用卖点**：关键数值带来直觉结果差异（如超低功耗、极速充电、降噪深度）、传统方案 vs. 本品极化对比（对应 `M-020` / `M-034`）。
- **参考面积切分**：标题区 `18%–20%`｜中上“核心数值视觉锤或场景示意” `45%–50%`｜中下“结果仪表或双栏/双行极化对比区” `25%–30%`。
- **构图要点**：突出 1 组核心数值或 1 组直观对照（旧方案弱化、本品聚焦），避免把单页对比膨胀成十几行的密集长表。
- **推荐渲染路线**：三层管线——复杂实景/透视走 Layer 1（AI 统一渲染），精确数字与对比结论走 Layer 3（矢量压字）。

### 骨架 P-05：宏大实景 + 角落规格标牌骨架 (`environment-plus-spec-tag`)
- **适用卖点**：真实户外/生活/场馆环境融入、体量尺度参照（`M-001`）、耐候工况或空间氛围定调。
- **参考面积切分**：全出血真实环境摄影占 **`80%–100%`**（利用天空、墙面、地面等自然留白）｜产品或场馆置于真实光影与尺度中｜角落安置克制的规格/活动信息标牌占 **`≤ 15%`**。
- **构图要点**：让环境真实性本身承担说服力，必要的关键信息（日期、展位、防护等级或核心参数）落在干净负空间内确保一眼可读。
- **推荐渲染路线**：Layer 1（真实实拍原图或 AI 实景光影融合）+ Layer 3（精确矢量标题与信息标牌）。

### 骨架 P-06：正交功能网格 / 标配与规格骨架 (`orthographic-spec-grid`)
- **适用卖点**：外形尺寸标尺、接口全定义、标配全家福（`M-003`）、单栏语义分组规格表（`M-005`/`M-020`）、纯色远距大牌（`M-028`）。
- **参考面积切分**：按正文行高切分基线模数网格（`M-016`），保留清晰空白格与递增外边距（`M-017`），主体采用正交平视/俯视或平铺阵列。
- **构图要点**：无多余透视炫技，信息按语义分区清晰分组，数值列右对齐（`tabular-nums`）。
- **推荐渲染路线**：**通道 2（Python PIL / SVG 精确渲染）**主力阵地——若含真实产品正交图，只需保证棚拍均匀光影与底色一致，再由 Layer 2 高精抠图嵌入网格。

## 三、 多图套系编排节奏参考（3–5 张卖点海报）

当需要连续制作 **3–5 张同一产品的系列海报** 时，建议显式规划“统一资产 vs. 逐张变化”，避免每张图构图撞车：

| 套系维度 | 建议全套锁死的统一资产（保持品牌系列感） | 建议逐张切换的变化维度（防审美疲劳） |
| :--- | :--- | :--- |
| **3 张核心卖点套图** | ① 同一套顶栏标题挂线与字阶体系<br>② 同一套背景色温/台面材质与主光源方向<br>③ 同一套品牌主/辅色与标注样式 | - `P1`（核心结构/卖点）：如 `P-02` 主体特写 + 局部证据<br>- `P2`（多场景适应）：如 `P-03` 局部特写 + 多栏场景卡<br>- `P3`（数值/收益对比）：如 `P-04` 核心数字 + 极化对比 |
| **5 张完整详情页主线** | 同上（允许在纯参数/装箱页切入同色系 `P-06` 功能网格） | `P1`（`P-01` 或 `P-05` 首屏定调与尺度） $\rightarrow$ `P2`（`P-02` 核心结构证据） $\rightarrow$ `P3`（`P-03` 多工况场景） $\rightarrow$ `P4`（`P-04` 对比证言） $\rightarrow$ `P5`（`P-06` 标配全家福与规格参数表） |
