# 海报与套系构图骨架库 (Poster & Series Composition Patterns)

本指南将**“构图骨架（画面怎么切分、几大区块、几处焦点）”**与**“风格母版（光影、材质、色彩、字体）”**彻底解耦。无论采用 `library/styles/` 中的哪套实证风格母版，均可按卖点性质选配下列构图骨架，从源头杜绝“把所有元素塞进一张图、做成程序员 PPT/流程图”的通病。

---

## 一、 全局视觉预算硬红线（全骨架通用）

在为任何海报/详情页卖点屏排布元素前，必须先通过以下 4 条预算约束：

1. **单屏主焦点唯一**：任何一张图只能有 **1 个绝对视觉中心（Primary Hero）**，辅以 **最多 1 组辅助证据**（如 1 块精简 HUD、1 组三栏小卡或 2–3 条短引线）。**禁止**把“整机 + 密集监控大屏 + 2 个放大窗 + 复杂光路 + 多组粗边徽章”同时塞满同一画面。
2. **净留白底线**：画面保留至少 **`30%–45%`** 干净无杂字的背景呼吸区（大标题四周尤其不能贴边或被图形挤占）。
3. **容器极简原则**：优先用**字重落差、明度层级与 1px 细引线**建立结构，而非给每个标签、数字或短句套粗边框、实心药丸盒或霓虹描边。
4. **移动端可读红线**：凡压在图内的主标题、关键数字和短引线标签，缩至 `375px` 手机屏宽时必须清晰可读；超过 2 行的技术解释移至底部注脚或图外文案。

## 二、 6 套正交海报构图骨架

### 骨架 P-01：单品剧场微距骨架 (`hero-studio-macro`)
- **适用卖点**：旗舰外观、核心工艺、金属/皮革/织物材质质感、品牌首屏定调。
- **版面面积切分**：顶部标题与留白区 `22%–28%`｜中部单品主视觉 `45%–55%`｜底部留白或单一短注脚 `15%–20%`。
- **元素上限**：1 个主体 + 1 组主副标题 + 最多 1 个极简底部认证/规格锚点；**禁止加引线和多卡片**。
- **推荐渲染路线**：三层管线——Layer 1（AI 统一影棚光影重构或纯影棚底图）+ Layer 2（原厂铭牌/Logo 局部保真）+ Layer 3（矢量压字）。

### 骨架 P-02：硬件证据与引线/光路骨架 (`hardware-evidence-callout`)
- **适用卖点**：结构亮点、接口功能、信号采集、内部防护（对应 `M-002`）。
- **版面面积切分**：顶部标题区 `18%–22%`｜核心硬件大视角主体 `42%–50%`｜单一精简证据模块（如极简半透明 HUD 或 1 个局部细节证言）`15%–20%`｜底部单一工程背书条 `8%–10%`。
- **元素上限**：引线总数 **`≤ 3` 条**；若含信号/光路表达，**起点必须 100% 落在实物对应物理接口上**，线条纤细通透且不遮挡硬件核心丝印。
- **严禁反模式**：禁止用代码画 20+ 格高饱和描边小框把辅助面板做成喧宾夺主的后台表格。
- **推荐渲染路线**：三层管线——原图与目标场景光影反差大时，强制走 Layer 1（AI 统一暗场/影棚光影与自然发光氛围）+ Layer 2（铭牌/二维码/丝印无损 `patch`）+ Layer 3（精确矢量文字与细引线）。

### 骨架 P-03：主视窗 + 底部多栏场景证据骨架 (`hero-plus-scenario-grid`)
- **适用卖点**：一项核心能力覆盖 2–3 种典型工况/场景（如三重防打火、多设备兼容、多模式切换，对应 `M-016` 模数网格）。
- **版面面积切分**：顶部标题区 `18%–20%`｜上半部硬件关键部位特写主视窗 `38%–44%`｜下半部 2 栏或 3 栏等宽等高场景证据卡 `32%–36%`。
- **元素上限**：下半部卡片最多 **3 栏**，每卡只含“1 张统一光影小图 + 1 个编号/短标题 + 1 句 10–15 词短说明”，顶底严格共线对齐。
- **推荐渲染路线**：三层管线——Layer 1 统一生成上半部硬件特写与下半部同色温场景图，Layer 3 精准排布三栏等宽网格与清晰英文/中文说明。

### 骨架 P-04：因果双屏 / 极化对比骨架 (`cause-effect-or-comparison`)
- **适用卖点**：微小参数带来巨大结果差异（如 5 mA 暗电流检测 $\rightarrow$ 真实 SOC）、传统方案 vs. 本品极化对比（对应 `M-020` / `M-034`）。
- **版面面积切分**：顶部标题区 `18%–20%`｜中上“因/核心参数锚点 + 应用载体示意” `45%–50%`｜中下“果/高精度仪表或双行极化对比卡” `25%–30%`。
- **元素上限**：全屏锁死 **1 个超大核心数值视觉锤**（如 `5 mA`），对比维度控制在 **1 组双行/双列直观对照**（传统方案压暗弱化，本品高亮聚焦），严禁把对比做成 10 行大表格。
- **推荐渲染路线**：三层管线——复杂载体透视图与质感仪表走 Layer 1（AI 统一渲染），精确数字与对比结论走 Layer 3（矢量压字）。

### 骨架 P-05：宏大实景 + 装备吊牌参数骨架 (`environment-plus-spec-tag`)
- **适用卖点**：三防/耐候/户外真实工况、真实体量尺度参照（`M-001`）、家居空间融入感。
- **版面面积切分**：全出血真实环境摄影占 **`80%–100%`**（其中自然环境负空间如天空/岩壁/墙面占 `≥ 35%`）｜产品置于真实光影与尺度中｜角落安置极克制的“吊牌式技术标号/简短规格块”占 **`≤ 12%`**。
- **元素上限**：无复杂卡片和多层弹窗，用环境真实性承担说服力，参数仅以极简等宽技术字（如 `IP67 · -30°C~75°C`）落于静谧负空间。
- **推荐渲染路线**：Layer 1（AI 实景融合重构或真实外景实拍）+ Layer 3（极简矢量标题与技术标牌）。

### 骨架 P-06：正交功能网格 / 标配与参数骨架 (`orthographic-spec-grid`)
- **适用卖点**：外形尺寸标尺、接口全定义、标配全家福（`M-003`）、单栏语义分组规格表（`M-005`/`M-020`）、纯色远距大牌（`M-028`）。
- **版面面积切分**：严格按正文行高切分基线模数网格（`M-016`），保留 `≥ 30%` 空白格与递增外边距（`M-017`），主体采用纯正交平视/俯视。
- **元素上限**：无透视炫技、无霓虹特效，信息按语义分区清晰分组，数字列右对齐（`tabular-nums`）。
- **推荐渲染路线**：**通道 2（Python PIL / SVG 精确渲染）**主力阵地——若含真实产品正交图，只需保证其棚拍均匀光影与浅灰/纸白底色一致，再由 Layer 2 高精抠图嵌入网格。

## 三、 多图套系编排节奏模板（3–5 张卖点海报）

当需要连续制作 **3–5 张同一产品的系列海报** 时，必须显式填写下表，确保**“套系视觉统一，单张构图不撞车”**：

| 套系维度 | 必须全套锁死的统一资产（保持品牌系列感） | 必须逐张切换的变化维度（防审美疲劳） |
| :--- | :--- | :--- |
| **3 张核心卖点套图** | ① 同一套顶栏标题挂线高度与字阶<br>② 同一套背景色温/台面材质与主光源方向<br>③ 同一套唯一信号色与极简引线/HUD 样式 | - `P1`（核心结构/原理卖点）：用 `P-02` 硬件大微距 + 单一证据<br>- `P2`（多场景防护卖点）：用 `P-03` 局部特写 + 底部三栏场景卡<br>- `P3`（精度/收益对比卖点）：用 `P-04` 超大核心数字 + 载体透视/双行对比 |
| **5 张完整详情页主线** | 同上（允许在最后 1 张纯参数/装箱页切入同色系 `P-06` 浅色/暗色功能网格） | `P1`（`P-01` 或 `P-05` 首屏定调与尺度） $\rightarrow$ `P2`（`P-02` 核心工艺/结构证据） $\rightarrow$ `P3`（`P-03` 多工况场景卡） $\rightarrow$ `P4`（`P-04` 数据对比证言） $\rightarrow$ `P5`（`P-06` 标配全家福与规格参数表） |
