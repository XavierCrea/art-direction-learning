# Baymard 图文引线标注实验：用图内结构引线与短标签弥合“只看图不读字”的断层

[中文案例索引](../README.md) · [English](en/C-baymard-descriptive-callouts.md)

[返回视觉案例库](../README.md) · 独立可用性测试与电商行业基准研究

- **卡点症状 (`when_stuck`)**　拍了高清局部特写图或把核心卖点（如防水、防雨、口袋尺寸、排风口间隙）写在了文字描述里，但买家只滑图片不看长文，看着局部特写一脸茫然（“这拍的是啥？”）并直接跳失。
- **适用载体**　电商详情页主图画廊（PDP Gallery）、产品卖点拆解图（Feature Callout Image）、工业零部件细节图。

## 原材料里看到什么 (`observations`)

- Baymard Institute 测试发现：**56%** 的买家进页先翻看产品图，且大量买家在初筛阶段极度抗拒阅读长篇文字描述或参数表；与此同时，纯照片无法天然传达非视觉属性（如防雨等级、材质克重、内部隔层容纳尺寸），过度裁切的局部特写还会让买家迷失方位。
- **反面案例 1（Lowe's 烤炉燃烧器特写）**：图片只给了一个剧烈裁切的金属管与火焰特写，没有图注。受试者困惑道：“这是什么鬼？我看到火苗，但完全不知道这部件是干嘛的。”
- **反面案例 2（户外坐垫防雨属性漏看）**：受试者想确认庭院沙发坐垫淋雨是否要收进屋，先翻遍图片没看到防水提示，扫视正文又漏掉了藏在段落里的 `all weather fabric`，最终直接放弃该产品。
- **正面案例（水花图形 + 防水标签 / Lowe's 冰箱尺寸引线 / Amazon 电脑包）**：在蓝牙音箱周围加上飞溅水花与 `100% Waterproof` 标注、在冰箱图上直接画出长宽高及散热留空引线（原本藏在说明书深处）、在电脑包隔层拉出引线标明 `Fits up to 15.6" laptop` 与 `Water resistant`，受试者均在翻图时瞬间抓住了核心卖点并放慢速度深入研究。
- **移动端字号翻车警示（HP 手机端首屏）**：HP 直接把桌面端嵌了小字的横幅图缩小放进手机端，除标题 `Save up to $350` 外，下方的橙色按钮和两行说明文字缩成无法辨认的模糊色块。

## 图字如何分工 (`copy_visual_synergy`)

- **照片/视觉图形负责“锁定物理位置与感官状态”**：展示部件在整机上的位置、材质纹理或水花/承重等物理状态。
- **引线与短标签（Callout Text）负责“定性与定量点破”**：用 2–6 个词的短标签（如 `304 Stainless Steel Burner`、`IPX7 Waterproof`、`Fits 15.6" Laptop`）直接指向对应部位，替买家省去“看图猜谜”和“去正文里大海捞针”的精力。

## 可迁移的视觉动作 (`reusable_move`)

1. 挑出买家最关心的 2–4 个非显性卖点（如防水/防火等级、核心材质、兼容尺寸、安装留空距离）或容易看懵的局部特写。
2. 在产品图上用清晰的细引线（Leader Line）指向具体部位，配高对比度短标签（每条标签控制在 3–6 个单词或 10 个汉字以内）。
3. 若为局部微距特写，在角落附带整机小缩略图圈出所在位置，或用图注点明“部件名称 + 对买家的实际作用”。
4. **执行移动端可读性体检**：嵌入图片内部的文字在缩放到 375px 手机屏幕宽度时必须清晰可读；长句解释一律放到图片下方的 HTML 图注（Caption）中。

## 素材前提与迁移边界 (`asset_prerequisites` & `transfer_limits`)

- **素材前提**：引线指向的物理部位必须与工程结构一致；防水、阻燃、承重或尺寸数字必须有真实规格书支撑。
- **禁用边界**：一张图上的引线标注不超过 4 处，严禁把整段说明书直接塞进图片变成“图文牛皮癣”；严禁桌面与手机共用同一张含极小内嵌文字的图片。

## 已知效果与出处

- **证据属性**：独立可用性测试与行业基准统计（52% 的头部电商网站未对畅销品使用描述性图文标注）。
