# Baymard Included & Optional Accessories Study: Preventing Value Misjudgment with "Included in the Box" Knolling and "Sold Separately" Microcopy

[English Case Index](../README.en.md) · [简体中文](../C-baymard-included-optional-accessories.md) · Independent Usability Testing & E-Commerce Benchmark Study

- **Symptom (`when_stuck`)**: A product includes high-value accessories (harnesses, temperature probes, blades, chargers) that are only mentioned in text below the fold—so buyers think the product is overpriced—or gallery photos show optional add-ons without warning, leaving buyers feeling deceived when those items aren't in the box.
- **Channels**: E-commerce PDP image galleries, B2B equipment packing list visuals (`What's in the Box`), modular accessory showcases.

## What the Source Material Shows (`observations`)

- Baymard Institute's benchmark shows **31%** of major e-commerce sites fail to include an **"Included Accessories" image** in the main gallery for products that ship with accessories, while **13%** depict optional accessories in product images without clarifying that they cost extra (`44%` total failure rate).
- **Lost Sales from Hidden Bundled Value (`63%` of users missed it)**: During testing, a stand mixer that actually shipped with `3` high-grade steel beaters only listed them in the text description below the fold rather than showing them in the image gallery. As a result, **63%** of test subjects had no idea the beaters were included and falsely judged the mixer to be worse value than a competitor that pictured its attachments in the gallery.
- **Buyer Anger from Unlabeled Optional Add-Ons (IKEA Armchair + Ottoman / Home Depot Grill Insert)**:
  - IKEA photographed an armchair together with a matching ottoman and no text disclaimer; a test subject exclaimed what a great deal the set was, only to discover in the assembly details that the price covered only the chair.
  - Home Depot showed a grill with an optional insert and vague text reading `"Additional Insert Options Available"`, leaving buyers unable to tell whether the pictured insert was included.
- **Positive Benchmarks (Argos / B&H Photo)**:
  - Argos vacuums and B&H cameras dedicate a gallery slide to a clean flat-lay (`Knolling`) showing the main unit alongside every strap, battery, and cable included in the box.
  - When B&H Photo displays a Microsoft Surface with a stylus and keyboard cover, it prints explicit microcopy directly on the image: **`"Keyboard Sold Separately"`**, eliminating all ambiguity. Meanwhile, **75%** of test subjects quickly discovered key product capabilities when core optional accessories were clearly depicted and labeled.

## How Copy and Visuals Work Together (`copy_visual_synergy`)

- **Visuals handle "physical inventory accounting"**: Arranging the main unit and every bundled accessory in a clean grid (`Knolling / Flat-lay`) lets buyers calculate total package value in one glance.
- **Copy handles "ownership boundary enforcement"**: Title the bundled flat-lay **`"Included in the Box"`**; whenever an optional accessory appears in a gallery photo to demonstrate expansion capability, place unmistakable **`"Sold Separately"`** microcopy right next to the item—never vague wording like `"Available"`.

## Reusable Visual Move (`reusable_move`)

1. Whenever a product ships with accessories (cables, brackets, adapters, spare parts, sensors), add 1 dedicated **"Included Accessories" (`What's in the Box`)** image to the main gallery showing the host unit and all bundled items arranged neatly with item names and quantities (`×2`).
2. When optional modules are a major selling point (e.g., multi-tool attachments, expansion battery packs, CANbus/RS485 dongles), include 1 **"Optional Accessories"** gallery slide that visually separates optional items in a dashed box or tinted zone labeled **`"Optional — Sold Separately"`**.
3. If a product has dozens of minor compatible accessories, keep them out of the primary image gallery and place them in a cross-sell section below.

## Asset Prerequisites & Transfer Limits (`asset_prerequisites` & `transfer_limits`)

- **Asset Prerequisite**: Cross-check the visual layout 100% against the warehouse Bill of Materials (`Packing List`).
- **Transfer Limit**: Never include non-bundled props (test meters, host laptops, optional mounting brackets) in product gallery shots without an explicit on-image `"Sold Separately"` disclaimer; never substitute diplomatic phrasing like `"Additional options available"` for `"Sold Separately"`.

- **Evidence Type**: Independent usability testing and benchmark statistics (`63%` missed text-only bundled accessories, `75%` discovered key features via optional accessory visuals, `31%` of sites lack included-accessory images).
