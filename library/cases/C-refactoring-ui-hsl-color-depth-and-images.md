## 一、原书对照实验与视觉观察（Verified Book Evidence）

### 1. 告别 5 色发生器：HSL 三类色板与 9 阶（100–900）预定义法（PDF p.138–151）
- **为什么 5 色发生器没法做真实界面（p.142–147）**：在线配色工具生成的 5 个孤立 Hex 色值一旦套进真实 UI 就会显得像刺眼的色块拼贴（p.142 反例）。一套真正可用的界面色板必须包含三大类、每类 **5–10 个明度阶梯**：
  1. **Greys（灰度色，8–10 阶，p.143–144）**：避开不自然的纯黑（True black），从极深灰递进到纯白；
  2. **Primary color(s)（品牌主色，5–10 阶，p.145）**：需要极浅阶（如 `100`）做提示底色、极深阶（如 `900`）做文字色；
  3. **Accent colors（语义与强调色，各 5–10 阶，p.145–147）**：红（危险/删除）、黄（警告）、绿（正向趋势）、青/紫（新功能高亮）。
- **9 阶色板二分构建法（Define your shades up front, p.148–151）**：
  - 先定中间基准色 **`500`**（适合做实心按钮背景的色阶），再定两端极值：**`900`**（最深文字色）与 **`100`**（最浅提示框底色，可在同一个 Alert 组件里同时调好 `100` 底色与 `900` 字色，p.149）；
  - 接着取折中点 **`700`** 与 **`300`**，最后填满 **`800, 600, 400, 200`**，形成完整的 `100–900` 九阶色板（p.150）。

### 2. U 型饱和度补偿、感知亮度公式与色相微旋调光法（PDF p.152–165）
- **明度极值吞噬饱和度（U 型补偿曲线，p.152）**：在 HSL 空间中，当明度（Lightness）趋近 `0%` 或 `100%` 时，相同的饱和度看起来会发灰发白；因此**越往色板两端（最亮/最暗阶）走，越要主动拉高 Saturation（呈 U 型曲线）**（p.152 图示）。
- **感知亮度（Perceived Brightness）与 3 亮峰 / 3 暗谷定律（p.153–157）**：
  - 黄色 `hsl(60, 100%, 50%)` 与蓝色 `hsl(240, 100%, 50%)` 的 HSL 明度同为 `50%`，但人眼觉得黄色亮得多（p.153），因为 RGB 感知亮度遵循公式：
    $$\text{Perceived Brightness} = \frac{\sqrt{0.299r^2 + 0.587g^2 + 0.114b^2}}{255}$$
  - 色轮上存在 **3 个高亮极值点：黄色 `60°`、青色 `180°`、品红 `300°`**，以及 **3 个深暗极值点：红色 `0°`、绿色 `120°`、蓝色 `240°`**（p.154 曲线图）。
  - **色相微旋调光法（Changing brightness by rotating hue, p.155–157）**：
    - 想让颜色变亮且不发白：将色相（Hue）向最近的亮峰（`60° / 180° / 300°`）旋转（如蓝标从 `210°` 旋向 `190°`，p.155）；
    - 想让颜色变暗且不发脏：将色相向最近的暗谷（`0° / 120° / 240°`）旋转——例如制作黄色色板的深色阶时，单纯降 Lightness 会变成发臭的泥褐色（p.156 `✗` 反例），而**边降明度边把色相往橙红色（`0°` 方向，如从 `50°` 旋向 `32°`）旋转**，就能得到浓郁温暖的琥珀金棕色（p.156 `✓` 正例）。每次旋转控制在 **`20°–30°` 以内**（p.157）。
- **有色温的灰（Greys don't have to be grey, p.158–161）**：给灰阶注入少量蓝色（`Hue ~210°`）得冷峻科技灰，注入少量黄橙色（`Hue ~40°`）得温暖亲和灰（p.159）。
- **翻转对比度过 WCAG 4.5:1（Flipping the contrast, p.162–165）**：深彩底配白字要想达到 WCAG `4.5:1` 对比度，底色必须压得很深，结果次要标签变成全页最抢眼的实心黑块（p.163 `✗`）；**翻转对比度，改用“浅色系底板（100/200 阶）+ 深同色系文字（800/900 阶）”**，既轻松达标 `4.5:1` 又丝毫不抢主视觉风头（p.164 `✓`）。

### 3. 顶光模拟、5 级海拔与双层组合阴影（PDF p.172–196, p.252）
- **模拟自然顶光（Light comes from above, p.172–179）**：
  - **凸起元素（Raised，如按钮/卡片，p.175–176）**：顶边朝天受光，用手工挑选的同色系浅色加 `1px` 顶边高光（`border-top` 或 `inset 0 1px 0`，禁用半透明白以免冲淡饱和度），底部加小模糊垂直偏移暗影；
  - **凹陷元素（Inset，如输入框/凹槽 Well，p.177–178）**：顶部被上沿遮光加微弱内阴影（`inset 0 2px 4px`），底唇朝天受光加浅色底边。
- **双层阴影各司其职（Shadows can have two parts, p.186–189, p.252）**：
  - **第 1 层阴影（主光源投射）**：较大垂直偏移 + 较大模糊半径（如 `0 15px 35px hsla(0,0%,0%,0.1)` 或 `0 5px 15px hsla(0,0%,0%,0.1)`）；
  - **第 2 层阴影（环境光遮蔽紧贴暗部）**：极小垂直偏移 + 小模糊半径（如 `0 4px 6px hsla(0,0%,0%,0.07)`）；且当元素海拔升至最高（如弹窗浮起）时，这层紧贴底部的环境暗影应逐渐淡化消失（p.188–189）。
- **跨界叠层与图片隐形边框（Overlap elements to create layers, p.194–196）**：让重点卡片跨越深浅两段背景色交界线（p.194），或让主推卡片高度超出父容器上下边缘（p.195）；多张图片叠放时，给上层图片加一圈**与页面背景同色的“隐形边框（Invisible border）”**，彻底消除图片边缘咬合打架（p.196）。

### 4. 背景大图文字对比度四解法与防缩略/防出血失真（PDF p.202–217）
- **解决背景照片明暗不均导致文字看不清的 4 种标准动作（Text needs consistent contrast, p.202–207）**：
  1. **加半透明黑/白遮罩（Add an overlay, p.203–204）**；
  2. **单独压低照片自身对比度并补偿亮度（Lower the image contrast, p.204）**；
  3. **三步单色化品牌染图（Colorize the image, p.205）**：① 降低照片对比度 → ② 去色转为黑白灰度（Desaturate） → ③ 叠加上层品牌纯色并使用 **`multiply`（正片叠底）** 混合模式；
  4. **零偏移大半径文字发光暗影（Add a text shadow, p.206）**：用大模糊半径、零偏移（`0 0 20px`）的微光托底文字。
- **严禁把全屏截图缩小 70% 成 4px 蚊子字（p.210–212）**：在特性区展示复杂软件/系统界面时，改为截取平板窄视口、只截局部核心特写（Partial screenshot），或重绘去文字的极简线框示意图（Simplified UI）。
- **防浅色图片与白底融合出血（Prevent background bleed, p.216–217）**：不用生硬实线外框，改用微妙的**内阴影（`inset 0 0 0 1px hsla(0,0%,0%,0.1)`）或半透明内边框**锁住图片轮廓。

## 二、图文协同机制（Copy-Visual Synergy）
- **背景图退让、标题零阻力识别**：通过“降对比 + 去色 + 正片叠底品牌色”三步法，既保留了真实场景照片的肌理与临场感，又把整张照片拉平为稳定的单色低动态底板，让白色主标题在任何位置都拥有刀刻般的清晰对比度。

## 三、可复用视觉动作（Reusable Move）
1. **建色板**：按 `100–900` 九阶预定义冷/暖灰阶、主色与语义色；往两端拉高饱和度，调亮向 `60°/180°/300°` 微旋色相，调暗（尤其黄/金/橙）向 `0°/120°/240°` 微旋色相；次级徽章一律“浅底深字”翻转对比度。
2. **赋景深**：卡片与按钮采用“顶部 1px 手选浅色高光 + 底部双层组合阴影”，重点模块跨背景交界线叠放，叠图加背景同色隐形边框。
3. **控底图**：首屏照片压字统一执行“半透明渐变遮罩”或“降对比+去色+正片叠底单色化”，白底浅色商品图加 `1px` 半透明内阴影防融底。

---

## 四、迁移边界（Transfer Limits）
- 色相微旋调光每次旋转幅度不得超过 `20°–30°`，否则会变成另一种颜色；
- “降对比+去色+正片叠底单色化”适用于烘托气氛的首屏背景图或宣发海报底图，**严禁用于需要展示真实商品颜色与材质细节的电商主图（PDP Gallery）**。
