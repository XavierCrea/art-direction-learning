- **卡点症状 (`when_stuck`)**　需要表达“看不见的底层安全机制、传感器、防抖/降噪/均衡算法或物理纠偏能力”，但画事故现场显得血腥丑陋、画工程原理图太晦涩、放产品外观图又完全看不出这项隐形技术。
- **适用载体**　品牌技术形象海报（Print / OOH）、高端新品亮点页（Hero / Feature Section）、极简社媒知识卡（Social Minimal Card），天然适配**通道 2（Python PIL / SVG 矢量精准直出）**。

## 原材料里看到什么 (`observations`)

- **出处与背景**：**Mercedes-Benz** 平面广告 *Rollover Sensor*（代理商 Jung von Matt/Donau，奥地利维也纳，2007 年 3 月，1 张横版印刷稿）。
- **构图与极简留白**：横版冷灰/淡紫灰纯色底场，**超过 85% 面积为纯粹负空间**；全图没有汽车、没有道路、没有人物，也**没有大号主标题**。
- **核心视觉装置（4 帧符号逐帧演进）**：画面正中水平横排 **4 枚等大的金属质感奔驰三叉星徽标**，从左到右呈现清晰的旋转回正序列：
  1. **第 1 枚（最左）**：严重倾翻（偏转约 140–150°，主星尖指向右下）；
  2. **第 2 枚**：逐步回正（主星尖指向约 10 点钟）；
  3. **第 3 枚**：接近直立（微倾至约 11 点钟）；
  4. **第 4 枚（最右）**：完全归位直立，正下方锁定黑色衬线体 `Mercedes-Benz` 品牌字标。
- **静默底注（Whisper Reveal）**：右下角边距处仅放极小一行黑色衬线德文——**`Der Überschlagsensor. Aktiviert Schutzsysteme, bevor es zu spät ist. Nur ein Mercedes ist ein Mercedes.`**（“翻滚传感器。在为时已晚前激活保护系统。唯有奔驰，方为奔驰。”）。

## 图字如何分工 (`copy_visual_synergy`)

- **画面负责“1 秒视觉谜题 + 静态演动态”**：把人尽皆知的奔驰星标本身当作陀螺仪/倾角图解，让读者瞬间产生疑问（“为什么前三个标志是歪的，一路扶正到第四个？”），在不展示任何事故画面的前提下直觉感知到“倾翻与纠偏”。
- **右下角极小一行字负责“静默揭晓”**：取消大标题避免提前剧透，用极克制的一句话报出技术名称与核心价值，把“顿悟的快感”留给读者自己完成。

## 可迁移的视觉动作 (`reusable_move`)

1. **用 3–5 帧“单一符号状态序列”把隐形技术可视化**：
   - 当核心卖点是肉眼看不见的物理保护、校准、降噪或均衡能力时，选定 1 个大众一眼认得“常态基准”的极简几何符号（如自带方向感的知名 Logo，或电池柱/声波线/水平仪/液面等通用物理图标），横排 3–5 帧演完 **`异常/失衡 → 纠偏 → 归位稳定`** 全过程。
2. **锁定 80%+ 负空间与单轴居中排布**：
   - 删掉背景照片、装饰渐变与大号主标题，让 3–5 个等距符号成为全画幅唯一视觉线索（可直接用通道 2 Python PIL / SVG 矢量旋转或形变 100% 精准生成）。
3. **用“静默底注（Whisper Reveal）”收口**：
   - 将功能名 + 一句结果收益压在右下角或终帧下方，字号极度克制，服务于高端技术品牌的冷静专业感。

## 素材前提与迁移边界 (`asset_prerequisites` & `transfer_limits`)

- **素材前提**：用于逐帧演进的符号必须具备**公众 0.3 秒就能认出的“标准常态/朝向”**；若品牌本身知名度不高或 Logo 无明确方向感，必须改用通用物理符号（如电池格、声波、水平线）而非硬转陌生 Logo。
- **禁用边界**：本技法依赖读者 1–2 秒的自主顿悟，**不适用于急需 0.5 秒亮价格促单的电商促销图或低客单价硬广**；严禁超过 6 帧导致序列拖沓失去一眼通读感。
