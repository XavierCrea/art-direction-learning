- **卡点症状 (`when_stuck`)**　推广无形服务、SaaS 工具、版权/维权/招聘或行业活动时，没有好看的实物产品图，硬凑抽象 3D 插画或图库握手照又显得假大空且在街头/信息流里毫无停滑力。
- **适用载体**　线下街头/展会纯字海报（OOH / Event Poster）、小红书/社媒大字报封面（Social Typography Card）、无实物 SaaS/服务推广图（Ad Banner），高度适配**通道 2（Python PIL / SVG 像素级直出）**。

## 原材料里看到什么 (`observations`)

- **出处与背景**：音乐版权管理科技公司 **Muserk**（代理商 GS&F，2024 年 5 月，美国纳什维尔街头张贴系列海报，共 3 款纯字体执行稿）。
- **零照片/零插画的纯字体墙结构**：
  - **底色与唯一主视觉**：纯黑高对比底场（Pitch Black），画面中部约 **60% 面积**完全由顶天立地、左右贴边的**超窄粗体全大写荧光粉/品红巨字块**（紧行距）撑满，例如：
    - `EVERY SONG. / EVERY ROYALTY. / EVERY F'N CENT.`
    - `GET WHAT'S F'N / YOURS. TAKE / NOTHING LESS.`
    - `RELENTLESSLY / SEARCHING FOR / ROYALTIES.`
  - **清晰的三级字阶落差（3-Tier Scale Drop）**：
    1. **主层级（远距 10–30m 截停）**：占幅 60% 的荧光粉超窄粗体巨字；
    2. **次层级（中距 2–5m 讲清立场）**：巨字下方 3 行宽字距中号纯白无衬线大写副标（`WE'RE HELL-BENT ON TRACKING DOWN EVERY ROYALTY YOUR CATALOG GENERATES.`）；
    3. **行动收口层（近距 1m 转化）**：左下角极小常规字重说明 + 加粗短域名（`MUSERK.COM/FIXTHEPROBLEM`），右下角对称放置**白边荧光粉定制二维码（中心嵌 M 标）**；顶部极小白色品牌名锚定归属。
- **色场与视觉张力**：整张海报严格锁死 **黑 + 荧光粉 + 纯白** 三色，模拟音乐重镇纳什维尔街头演出海报（Gig Poster）的原生张贴气质，直接融入目标受众（词曲作者）的审美语境。

## 图字如何分工 (`copy_visual_synergy`)

- **文字本身的几何体块就是画面**：在没有实物可拍的情况下，靠极端字号（巨字墙）、紧凑行距与黑底荧光粉的高纯度色差制造物理视觉冲击力，远看是一堵不可忽视的色块墙，近看是直戳行业痛点的宣言。
- **底部“左短链 + 右高对比二维码”承接即时转化**：上方用情绪宣言拦住人，底部不废话，直接给出极易扫视的行动路径。

## 可迁移的视觉动作 (`reusable_move`)

1. **无实物可拍时，彻底放弃廉价插画，改用“60% 压缩粗体字墙”当主视觉**：
   - 将痛点或核心承诺压缩成 6–9 个强动词/强名词短句，用超窄高字重无衬线体（Condensed Bold）配极紧行距（`0.9–1.05`）占满版面中部 55%–65%。
2. **锁定“三色 + 三级极端字阶落差”骨骼**：
   - 配色严格限制为 **`1 个深色/纯黑高反差底 + 1 个高饱和品牌荧光/主强调色（仅用于巨字与二维码） + 1 个纯白/浅灰功能字色`**；
   - 字号严格按 `巨字主视觉（100%） → 中号副标（22%–28%） → 底部行动小字（10%–14%）` 拉开，避免各级字号接近发糊。
3. **底角双锚收口（左短网址 + 右反白框二维码）**：
   - 与通道 2（Python PIL / SVG + `zxingcpp` 校验）天然契合，可 100% 精准对齐网格与二维码静区。

## 素材前提与迁移边界 (`asset_prerequisites` & `transfer_limits`)

- **素材前提**：必须具备真正戳中受众痛点、足够锋利简短的 6–9 词宣言（如果文案平庸空洞，放大到 60% 画面只会把空话放大得更尴尬）。
- **禁用边界**：切忌把 20–30 字的长段落塞进巨字墙；街头/社媒使用粗口或反叛语气须严格匹配品牌调性与平台合规边界，B2B 严肃工业场景应保留其“黑底+高饱和巨字+三级落差+底角码”骨架，替换为克制硬核的数据/承诺短句。
