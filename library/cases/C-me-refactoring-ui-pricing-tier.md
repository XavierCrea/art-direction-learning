# Refactoring UI 与 Basecamp 定价视觉锚定：用版面面积、字号对比与交付物拆解重塑价格感知

[中文案例索引](../README.md) · [English](en/C-me-refactoring-ui-pricing-tier.md)

[返回视觉案例库](../README.md) · 落地页定价版式案例与实测销售占比

- **卡点症状 (`when_stuck`)**　产品定价高于同行普通低端品（如高配工业方案、定制套装或 $79–$149 的高价值产品），如果直接按普通单品排个价格数字，买家会用亚马逊/大路货的心理锚点嫌贵，或者只买最便宜的基础款。
- **适用载体**　着陆页定价区（Pricing Section）、B2B 样品包/方案包对比卡、高配 vs. 标准配选型表。

## 原材料里看到什么 (`observations`)

- **案例 1：Refactoring UI 如何卖出 $149 高价并让 78% 买家选高配版**
  1. **用视觉交付物拆解跳出低价品类锚点（Escape the Context）**：普通商业书在 Amazon 只能卖 $10，因为“电子书（e-book）”这个品类形态锁死了买家的价格预期。Adam 和 Steve 自建独立站，在视觉上不展示“一本书”，而是平铺展示**整套设计工具包（PDF 书 + 视频教程 + 图标包 + 色板 + 组件库）**，将认知锚点从“买本书”切换为“买一套完整设计系统”。
  2. **给主推高配档位（$149 vs. $79）倾斜 3 项视觉权重**：
     - **版面面积翻倍**：$149 的高配卡片占据了 $79 基础卡片 **2 倍的屏幕面积（Twice as much screen space）**；
     - **字号与主色按钮独占**：高配档使用更大字号与唯一的主色实心购买按钮（Primary Button Color），而低配档按钮被弱化；
     - **不对称折扣与命名锚定**：高配档标明直降 $100（40% off）并命名为 *“The Complete Package”*（暗示选低配就会错失完整体系），低配档仅降 $20（25% off）。
  3. **实测结果**：截至 2019 年 1 月 10 日，总计购买中 **78%（6,765 份）** 的买家选择了 $149 的高配档，总营收突破 135 万美元。
- **案例 2：Basecamp 如何让 $99/月显得便宜**
  - 在展示 $99/月价格之前，先用视觉对比清单列出企业如果分别采购群聊、网盘、项目管理等 5 款按人头收费的软件每月需花费数百至上千美元，在买家看到 $99 之前先立住高价参照系。

## 图字如何分工 (`copy_visual_synergy`)

- **画面与版面比例负责“重塑参照物与主次权重”**：把单一产品拆解成看得见的多组件矩阵图（脱离廉价单品印象），并用 **2:1 的卡片面积比 + 实心主色按钮** 告诉眼睛“哪一档才是标准答案”。
- **文案负责“前置高成本参照与完整性命名”**：在价格出现前先算清替代方案的隐性总成本（如分批采购线束、软件、售后或宕机损耗），并将主推档命名为“完整即用方案（Complete / Turnkey Kit）”。

## 可迁移的视觉动作 (`reusable_move`)

1. **视觉拆解交付物全家福**：卖高单价产品或高配定制包时，不要只放一张孤零零的产品外观图；把随附的上位机软件、通讯线束、测试报告、质保服务、安装支架全部可视化画进交付矩阵里。
2. **主推档位版面 2:1 倾斜**：在并排展示“标准版 vs. 高配完整版”时，让主推档占据更宽/更高的卡片面积、加醒目顶边条、用实心高对比按钮，将基础版设为浅色描边按钮。
3. **价格上方前置成本对比锚点**：在报价数字或套餐表正上方，先用一张简洁对比行展示“传统分散采购/故障停机成本 vs. 一体化方案总成本”。

## 素材前提与迁移边界 (`asset_prerequisites` & `transfer_limits`)

- **素材前提**：高配档拆解出的每一项子交付物（软件、配件、检测报告、技术支持）必须是真实可交付的资产；原价与折扣必须符合真实定价策略，严禁虚构虚假原价。
- **禁用边界**：Harry Dry 特别指出，Refactoring UI 能定高价的根本前提是此前两年持续输出了大量免费干货建立了极高信任——版面技巧只能放大已有价值的转化，不能替劣质产品凭空变出溢价。

## 已知效果与出处

- **证据属性**：Refactoring UI 78% 高配占比与 $1.35M 营收来自创始人播客披露（Author Reported / Case Study Metric）；Basecamp 为落地页结构分析。
