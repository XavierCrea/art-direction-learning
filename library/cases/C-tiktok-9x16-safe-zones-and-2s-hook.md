# TikTok Creative Center 9:16 竖屏安全区与前 2–3 秒视觉钩子：像素级避让红线与早期露品实证

[中文案例索引](../README.md) · [English](en/C-tiktok-9x16-safe-zones-and-2s-hook.md)

[返回视觉案例库](../README.md) · 短视频与竖屏信息流官方实证基准

- **卡点症状 (`when_stuck`)**　9:16 竖屏广告、短视频封面或信息流物料投放到 TikTok / 抖音 / Reels 后，核心标题、卖点或价格被右侧点赞评论栏或底部文案与 CTA 遮挡；或者沿用传统 TVC 慢热片头导致前 2 秒即被划走、品牌回忆度极低。
- **适用载体**　TikTok / 抖音 / Instagram Reels / YouTube Shorts 9:16 竖屏信息流视频与静态贴片（Vertical Social Feed）。

## 原材料里看到什么 (`observations`)

- **标准 `1080 × 1920 px`（9:16）信息流 UI 安全区像素红线**：
  - **顶部避让（Top Margin）**：至少留空 **`240 px`**（约占画高 `12.5%–14%`），避让顶部状态栏与“关注/推荐”标签；
  - **底部避让（Bottom Margin）**：至少留空 **`660 px`**（约占画高 `35%`），避让账号名、正文文案、音乐条与原生 CTA 按钮（若文案较长或挂锚点组件，遮挡区会进一步上移）；
  - **左侧避让（Left Margin）**：至少留空 **`120 px`**；
  - **右侧避让（Right Margin）**：上半区至少留空 **`120 px`**，下半区扩大至 **`180–300 px`**，避让头像、点赞、评论、收藏、转发互动纵列。
- **前 2–3 秒视觉钩子与官方平台研究数据**：
  - TikTok Creative Center 明确反对传统电视广告式慢前奏，要求在 **前 2 秒内** 用动态动作、直接提问或强烈视觉痛点打破刷屏惯性；
  - 要求在 **前 2–3 秒内** 清晰呈现核心信息、产品本体或品牌标识，以防用户提前划走导致零回忆；
  - 平台研究数据显示：早期清晰展示产品最高可带来 **+65% 品牌好感度提升（Brand Affinity Lift）**；开场窗口承载了整条素材最高 **90% 的广告回忆价值（Ad Recall Value）**；**88%** 的 TikTok 用户认为音频是核心体验，因此前 3 秒需声画同步（配音/热曲 + 安全区内同步花字）。

## 图字如何分工 (`copy_visual_synergy`)

- **中上黄金安全区（避开顶 240px / 底 660px / 右下 180–300px）承载核心产品动作与大号短花字**：保证任何机型和投放位下文字 0 遮挡。
- **动态首帧 + 声画双轨**：画面在 0–2 秒直接演“痛点冲突或产品运转实况”，同步花字用 6–10 字点破结论，兼顾开声用户（88%）与静音刷屏场景。

## 可迁移的视觉动作 (`reusable_move`)

1. **所有 9:16 物料出图/剪辑前强制套用 `1080×1920` 安全区网格**：
   - 将主标题、价格、核心产品主体严格锁在 `x: 120–780px`（下半区避右 300px）、`y: 240–1260px` 的中心安全框内；通道 2（Python PIL/SVG）或剪辑模板直接内置 Safe Zone 参考线。
2. **砍掉 3 秒品牌片头，实施“第 1 帧见产品/见冲突”**：
   - 0–2 秒内必须出现动态变化（手部拆箱、测试对比动作、局部特写推进）+ 产品本体清晰露脸，不把产品藏到结尾才揭晓。
3. **前 3 秒声画与花字双锁**：
   - 语音开场与安全区大号短字幕同频出现，确保无声浏览也能 1 秒读懂。

## 素材前提与迁移边界 (`asset_prerequisites` & `transfer_limits`)

- **素材前提**：需明确具体投放平台（TikTok / 抖音 / Reels / TopView 特殊首 3 秒缩放位）的最新 UI 遮挡参数，并准备前 2 秒可用的真实动态/产品实拍镜头。
- **禁用边界**：严禁把底部 `660 px` 留成突兀死白块（安全区是“不放核心字与关键主体”，背景画面仍应自然延展出血满屏）；TopView 开屏等特殊广告位前 3 秒有独立缩放边界，不可盲套普通信息流尺寸。
