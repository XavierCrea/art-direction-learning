## 1. 光影与材质语言（实样客观观察）
- **光源设定**：两套去霓虹化的纯正工业棚光——
  - **Keysight 实验室白棚系**：纯白 `#FFFFFF` 无影实验室底光，测试硬件抠图利落干净、真实接驳测试线与真实原生波形界面，与下方高压真实世界摄影（体育场、城市、车流、工程师现场）形成“实验室 $\rightarrow$ 现场”的硬核反差；
  - **Fluke 工业冷灰棚系**：沉稳冷蓝灰/钢灰渐变摄影棚（深岩灰蓝 $\rightarrow$ 浅冷灰台面），均匀照亮哑光机箱、散热孔、红黑/金属精密端子与高亮原生屏幕读数（如 `1.000 000 0 V` / `30.000 0 A`），拒绝赛博烟雾与蓝紫炫光。
- **工程细节真实性**：仪器/硬件屏幕里的数字与波形必须 100% 真实清晰（矢量或高清原生实拍贴回），页面上的公式、接口丝印（`OUTPUT` / `SENSE` / `GUARD`）和接线完全忠实于工程实际。

## 2. 样本中的典型构图与留白用法（参考区间）
- **Keysight 标尺因果构图（适合主卖点画报）**：
  - 样本常留 **`45%–60%`** 纯白 `#FFFFFF` 留白框架（左、上、下留足呼吸边）；
  - 中上方由一条贯穿全宽的**精密标尺刻度线（Ruler Tick Marks）**锚定，上方纯白区放真实测试硬件，下方内嵌真实严苛应用场景大图，以 2 条垂直细引线串起“实验室测得稳 $\rightarrow$ 现场真实工况稳”的因果关系。
- **Fluke 斜切分栏构图（适合 B2B 展会单页/选型海报）**：
  - 样本中净白/极浅灰信息区约占 **`50%–55%`**，冷灰工业摄影区以**利落几何斜切面（Diagonal Facets）**切入约占 **`40%–45%`**，信息区左对齐分组排列核心型号与要点，底部用品牌色梯形色块承载 CTA 与可扫描真二维码。

## 3. 色彩与字体纪律
- **核心“5%–10% 品牌点睛铁律”**：
  - 基底中性色占 **`90%+`**：纯白 `#FFFFFF`、冷实验室灰 `#EEF1F5`、深岩蓝灰 `#1E3246` / `#334155`、正文深炭灰 `#4B5563`；
  - **品牌高亮色严格压在 `5%–10%` 面积内**（Keysight 猩红仅给标尺刻度线、两句短标题、公式结论关键词和 Logo；Fluke 工程黄仅给右上角 Logo 矩形块和左下角 CTA 梯形块），**彻底杜绝把整张海报染成高饱和品牌色或青蓝发光底**。
- **字体排布**：
  - Keysight 系：纤细优雅的 Light/Regular 现代无衬线大标题 + 窄体紧凑深灰小字说明 + 底部全大写粗窄体核心公式（`HARDWARE + SOFTWARE + PEOPLE = 5G INSIGHTS`）；
  - Fluke 系：稳重粗体深海蓝无衬线大标题 + 中蓝副标题 + 左对齐简洁要点列表，清晰易扫、极像国际大厂工程手册。

## 4. 可单独借用的原子手法 vs. 整体复刻风格边界
- **可单独借用的原子手法（保留客户自有品牌色也可直接用）**：
  - **贯通精密标尺刻度线（Keysight）**：用极细刻度尺串联“实验室硬件 $\rightarrow$ 真实工况”视觉因果（标尺红可无缝替换为客户品牌主色）；
  - **5%–10% 克制品牌色点睛**：90% 纯白/冷岩灰托底，仅把品牌色给标尺、核心数字、Logo 块或底部 CTA 梯形；
  - **几何斜切分栏（Fluke）**：用一道利落斜线切开产品棚拍区与纯白参数/要点区，打破呆板横竖两栏；
  - **极浅灰真实工程波形暗纹**：在留白角落铺极低对比真实测量波形，增加专业质感而不抢文字。
- **整体复刻时的风格注意项（仅在完整追求国际大厂仪器画报气质时参考）**：
  - 原样本回避满屏深蓝发光渐变、赛博网格、发光芯片、全息 UI 面板与大量粗边框小方框；仪器屏幕读数、工程公式与二维码须忠实还原并按 [output-qa-gate.md](../../references/output-qa-gate.md) 核验，严禁 AI 编造乱码或假公式。

## 5. 套系节奏规则（多图连出）
- **全套锁死**：90% 纯白/冷岩灰基调 + 5%–10% 单一品牌点睛色 + 统一的精密标尺刻度线（或利落斜切几何语言）+ 统一的底部公式/角标锚位。
- **逐图切换**：
  - **品牌/卖点海报系列（Keysight 路子）**：锁死顶部/中部标尺刻度线与硬件位置，逐张切换下方真实严苛工况大片（如体育场 / 城市 / 车流 / 高铁）与工程师现场公式；
  - **展会/选型系列（Fluke 路子）**：`3 层冷灰主机家族对比海报` $\rightarrow$ `斜切分栏核心卖点 + 端子微距 + 二维码单页` $\rightarrow$ `正面功能图标 + 背面 4 列标准对比表`。

## 6. 跨界适用场景与行业专精挂载槽
- **推荐跨界场景**：**BMS 保护板、示波器/万用表/测试仪器、储能逆变器、工业自动化控制器、传感器、电源模块与所有 B2B 硬核工程硬件的展会海报、产品单页和详情页卖点图**。
- **行业专精挂载规则**：迁移至嘉佰达 BMS 等产品时，直接把品牌色（蓝 `#00A0E0` / 绿 `#90C000`）压在 **5%–10%**（标尺刻度线、核心数字 `±10 kV` / `5 mA`、角标），大面积使用纯白 `#FFFFFF` 或冷岩灰托底；硬件主图按三层管线做实拍美化与铭牌无损 `patch`，标尺、数字、英文标题与二维码全部走代码像素级精确排版。
- **本地选图标准（`local/`）**：仅收高清、文字锐利可辨的真实工业仪器商业平面广告与产品单页，拒绝低清缩略图与无版式的纯白底 SKU 抠图。
