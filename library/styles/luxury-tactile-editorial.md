## 1. 光影与材质语言（实样客观观察）
- **光源设定**：**柔和定向顶斜光（Soft Sculpted Overhead Light）**，在纸卡厚度边缘、模切卡槽与玻璃小瓶下方投出极细腻真实的短软影，呈现手工精工制品的“可触摸感”。
- **背景与台面**：温润浅杏米白 `#F2EBE2` / 淡粉杏 `#EED5C9` 无缝哑光纸面，**零冰冷纯白 `#FFFFFF` 与死黑 `#000000`**。
- **材质刻画**：所有高级感来自**物理工艺本身**——厚重特种棉纸肌理（Textured Cotton Stock）、极细拉丝香槟金烫印（Gold Foil Stamping）、精准纸艺模切（Die-Cut）、玻璃与丝带般弯曲的纸卡结构，彻底抛弃浮夸发光 CG 特效。

## 2. 样本中的典型构图与留白用法（参考区间）
- **典型留白区间**：样本品牌故事/社论屏留白常在 **`50%+`**；静物工艺陈列屏常留 **`35%+`** 温润浅米底面负空间，物品之间留出呼吸间距。
- **标志性构图语言**：采用**精准 30°–45° 斜角秩序构图**（如整组模数包装斜向平铺，或奶油棉纸卡与赤陶橙卡呈优雅斜角叠放并由细长模切条串连），打破呆板居中同时保持严密秩序。
- **典型信息密度**：样本每张卡片信息极简（品牌主标 + 1 枚细线徽章 + 2 行克制小字）。

## 3. 色彩与字体纪律
- **色板观察**：
  - 样本采用暖调色盘（类爱马仕/南欧日光美学）：**饱和但沉稳的赤陶暖橙（`#E27A2E` 附近）** + **厚重奶油象牙白（`#F9F4EC`）** + **淡杏柔底（`#EAE2D7`）** + **深浓缩咖啡黑文字（`#231F1D`）** + **极细哑光烫金（`#B79056`）**；
  - 若客户自有品牌主色为蓝/绿等冷色，仍可保留客户品牌色，仅单独借用本样本的材质光影与斜角秩序手法（不必强制改色）。
- **字体排布**：**高对比喇叭口现代衬线体（Flared Luxury Serif）**配克制优雅的手写连笔弧线作视觉核心主标，辅以小号全大写宽字距无衬线体（`+0.12em`）排布信息与细长横线分隔（`+41 79 ... ——— email`），精细度极高。

## 4. 可单独借用的原子手法 vs. 整体复刻风格边界
- **可单独借用的原子手法（保留客户自有品牌色也可直接用）**：
  - **柔和定向侧顶光显纸张/工艺厚度**：靠真实斜光在纸卡边缘、模切槽与器物下方投出细腻短软影（即使换成客户品牌蓝底/深色卡纸同样成立）；
  - **30°–45° 模数斜角静物排布**：用精准斜角阵列制造高级秩序感与呼吸感；
  - **宽字距小号全大写信息行 + 细长横线分隔**：如 `+41 79 ... ——— email` 的精致联系栏排版；
  - **极简概念推导式社论叙事页**：大面积棉纸留白中放 1 段克制短文 + 细线徽章。
- **整体复刻时的风格注意项（仅在完整追求本案南欧暖调纸艺气质时参考）**：
  - 原样本回避黑金炫光粒子、廉价金色 3D 渐变字、圆角 UI 按钮、大促价签与厚重粗黑体，也未引入荧光色或冷调高饱和撞色；如仅借用单一手法或客户有明确品牌色规范，以客户品牌规范优先。

## 5. 套系节奏规则（多图连出）
- **全套锁死**：赤陶橙 + 奶油棉纸 + 深咖墨字 + 细线烫金徽章的统一材质色盘、高对比优雅衬线主标与柔和顶光短影。
- **逐图切换**：`45° 斜角阵列主视觉（建立强辨识色场与结构）` $\rightarrow$ `奶油纸底极简品牌叙事 + 概念逻辑图（A → B → C）` $\rightarrow$ `斜角叠放工艺微距（棉纸纤维 + 烫金反光 + 模切细节）`。

## 6. 跨界适用场景与行业专精挂载槽
- **推荐跨界场景**：**精品香氛美妆、轻奢皮具与箱包、高端礼盒与节日限定包装、珠宝腕表、设计师联名款消费电子/精品配件、以及所有想避开“黑金土味”的高客单礼赠海报**。
- **行业专精挂载规则**：用于实际产品或礼盒推广时，须如实还原产品本体包装比例、真实 Logo 工艺与瓶身/五金细节，严禁在后期生成中扭曲品牌衬线字形与纹章线条。
- **本地选图标准（`local/`）**：优先收集真实纸艺/皮革/烫金触感拍摄、经典斜角静物构图与极简品牌叙事屏（后续可混采 Chanel 黑白硬照或 Coach 皮革微距，或单独另建黑白高奢母版）。
