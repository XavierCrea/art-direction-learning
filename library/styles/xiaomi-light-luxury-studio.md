## 1. 光影与材质语言（实样客观观察）
- **光源设定**：高明度**珠宝级漫射柔光棚拍**，主光柔和顺滑地扫过缎光金属曲面与透明发声球，暗部通透绝不死黑；主体脚下仅留极轻的镜面地面反射或手掌自然接触阴影。
- **背景与台面**：90% 以上采用纯白 `#FFFFFF` 与极浅暖灰 `#F5F5F5` 无影棚；**仅在 IP57 抗汗抗水屏切为冷静中灰底（约 `#B7B8B7`）**，专门拉出透明水珠与珍珠白机身的反差。
- **材质与尺度刻画**：高频使用**真实干净的手部动作**（双指轻捏展示 `5.5g`、双指托起开盖科纳皮充电盒如珠宝盒、平摊掌心托举充电盒配续航指标），自然实现 `M-001` 比例参照，零违和感。

## 2. 样本中的典型构图与留白用法（参考区间）
- **典型留白区间**：样本主视觉屏与章节定调屏的净白/浅灰呼吸区常占 **`40%–55%`**。
- **典型的“字不压主体”布局**：
  - 首屏：左侧留白区放置品牌型号与 `｜` 分隔的 3 组短标签，右侧悬浮大尺寸主体，图文零重叠；
  - 爆炸图屏（`floor_8`）：上方左标题 + 右两段极简短文，下方全宽悬浮 7 零件水平爆炸图，图上零文字、零引线；
  - 章节定调屏（`DESIGN` / `TONE` / `EXPERIENCE`）：居中人像或开盒特写叠在超大淡米色英文水印前，左上角净留白仅放 8 个中文字。
- **典型信息密度**：样本单屏正文常占 **`≤ 18%`**；Bento 总览每格常见“1 行黑粗标题 + 2 行浅灰短句 + 1 张干净局部图”。

## 3. 色彩与字体纪律（实测 CSS 与画面提取）
- **色板结构**：
  - 基底与中性色占 **`92%+`**：画布 `#FFFFFF`、无边卡片 `#F5F5F5` / `#F4F4F4`、主标题深炭黑 `#191919`、正文次级灰 `#666666` / `#757575`；
  - **核心纪律——“正文 0 品牌亮橙，从产品主色提取点缀色”**：整套 23 屏正文完全不用小米橙，而是从主推配色“缎光金”提取低饱和**香槟沙金（约 `#B89B78` / `#C4A882`）**，仅克制用于 3 处：① 核心数字指标（`9h`、`38h`）；② 声学卖点副标题与 `1px` 引线；③ 章节背后极淡的米色英文水印（`#EAE3D5` / `#EFE8DA`）。
- **字体排布**：干净现代无衬线体（Helvetica Neue / 兰亭黑 / 思源黑体）；大标题与正文拉开清晰字号阶梯（约 `2.5x–3x`），关键数字指标（`9h`、`38h`）显著放大加粗，单位略缩半档。

## 4. 可单独借用的原子手法 vs. 整体复刻风格边界
- **可单独借用的原子手法（保留客户自有品牌色也可直接用）**：
  - **产品本体取色替代刺眼品牌色**：从产品自身材质/配色提取 1 支低饱和点缀色（样本中取香槟沙金），用于核心数字与细引线；
  - **真实干净手部尺度参照**：用双指轻捏、掌心托举自然呈现重量与大小（`M-001`）；
  - **超大淡色英文水印章节过场**：在白底人像/产品背后垫极低对比英文大词，切分长页视觉节奏；
  - **中灰底单屏反差切色**：唯独在防水/水珠屏切为冷静中灰底，瞬间拉出透明水珠与浅色机身的可辨度。
- **整体复刻时的风格注意项（仅在完整追求高明度轻奢白棚气质时参考）**：
  - 样本卡片靠 `#F5F5F5` 无描边圆角浅灰块自然分区，回避外描边与重投影，爆炸图与声学卡亦尽量克制方框与密集箭头；若实际产品确需品牌主色或明确接口标注，以用户指定品牌规范与买家理解优先。

## 5. 套系节奏规则（多屏/多图连出）
- **全套锁死**：高明度纯白/浅灰影棚基调、从产品本体提取的单一低饱和点缀色、无描边圆角浅灰卡与 `1px` 细引线语言。
- **逐屏切换**：
  1. **极简左字右图首屏**（`P-01` 变体，立住轻奢第一印象）
  2. **8 格非对称 Bento 卖点总览**（快速建立产品全貌）
  3. **全幅无字动态/静物呼吸屏**（清空视觉疲劳）
  4. **章节杂志水印人像屏（`DESIGN` / `TONE` / `EXPERIENCE`）**切分大篇章
  5. **篇章内交替换拍**：手部尺度微距 $\rightarrow$ 双栏局部微距 $\rightarrow$ 纯白无标注爆炸图 $\rightarrow$ 1px 引线结构卡 $\rightarrow$ 掌心大数字续航 $\rightarrow$ 中灰底水珠防水屏。

## 6. 跨界适用场景与行业专精挂载槽
- **推荐跨界场景**：高颜值消费电子、穿戴设备、医疗健康/个护小家电、精品配件、希望摆脱“廉价促销感”或“沉重暗黑风”的浅色工业单品详情页。
- **行业专精挂载规则**：迁移至垂直品类时，真实手部尺度参照（`M-001`）必须严格匹配实物真实长宽高；内部爆炸图（`floor_8` 类）必须依据真实 BOM/结构渲染，严禁 AI 编造不存在的内部元器件。
- **本地选图标准（`local/`）**：仅保留裁除顶部官网导航栏与底部黑边的纯净产品故事屏，优先涵盖首屏、Bento、大水印章节屏、无字爆炸图、1px 引线卡与手部大数字屏 6 类构图。
