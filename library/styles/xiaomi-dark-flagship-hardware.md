## 1. 光影与材质语言（实样客观观察）
- **光源设定**：**低键纯黑暗场聚光 + 冷银色精准轮廓切光**。大面积环境压成深邃纯黑 `#000000`，仅用一束克制的冷白/冷银侧向光切出哑光黑机身棱纹、金属接口内部针脚或芯片倒角高光；主机脚下铺暗拉丝石材/金属台面，带细腻低对比倒影。
- **内部透视与信号光路语言**：
  - 内部结构（`section-12`）：采用**烟熏半透明玻璃外壳透视**，仅点亮真实蚀刻铜金色 PCB 天线，拒绝廉价赛博霓虹；
  - 信号与芯片（`section-8` / `section-17` / `section-26`）：极纤细的冷银 PCB 走线反光、极克制的低饱和钢蓝信号同心圆与冷蓝/暖金双光轨，光效亮度永远让位于主标题和硬件主体。
- **材质刻画**：把所有高级感押注在真实工业质感（哑光竖向散热棱纹、金属 RJ45 端口内壁、芯片金属封盖倒角、暗调实景客厅）上。

## 2. 构图面积与留白预算（硬边界）
- **净留白底线**：纯黑暗场留白普遍达到 **`≥ 45%–55%`**，单屏只攻 **1 个硬核技术卖点**（芯片、网口、天线、速率、组网、可靠性测试各自独立成屏，绝不塞成一锅烩）。
- **字图严格分家**：
  - 左右分栏屏（Hero / 2.5G 网口 / 6 根隐藏天线）：左侧宽裕纯黑净区放左对齐文字，右侧放硬件微距或 X 光透视，图文零打架；
  - 上下分栏屏（芯片 / `20% ↑` 立体金属大字 / 客厅实景 / Mesh 户型图）：上方居中或左对齐简短文案，下方独立展示硬件或巨型视觉锤。
- **信息区上限**：单屏文案控制在 `1 句短眉标 + 1–2 行主标 + 2–3 行暗灰短说明`（占画面 `≤ 20%`）。

## 3. 色彩与字体纪律（实测 CSS Token）
- **色板结构**（源自 `index.1d7ac43b.css` 实测）：
  - 纯黑暗场与暗灰中性色占 **`94%+`**：画布 `#000000`、实体暗卡 `#0F0F0F`（圆角 `0.2rem` ≈ `11px`）、半透明浮卡 `rgba(0, 0, 0, 0.8)`（圆角 `0.3rem` ≈ `17px`）；
  - 文字三阶明度：主标题纯白 `#FFFFFF`、正文沉暗灰 `#999999` / `#949494`、脚注 `#666666`；
  - **核心纪律——依然“正文 0 小米橙”，统一香槟金属渐变金**：全页 26 屏唯一主点缀色为 CSS 垂直金属渐变 `linear-gradient(0deg, #e9c993, #e0bb7d, #dbb472)`（胶囊边框实测 `~1.1px solid #e8c790`），严格克制用于 4 处：① 眉标（如 `WiFi 7 芯片`、`2.5G网口聚合`）；② 章节 `1px` 空心细金边英文胶囊（`Speed` / `Disposition` / `Smart` / `Experience`）；③ Bento 分组标题；④ 核心可靠性/速率大数字（`3.6Gbps`、`≥220000次`、`715台`）。
- **字体排布**（实测 `MILanPro_Medium2` 体系，1440px 下 `1rem = 56.25px`）：
  - 章节超大标题 `67.5px`（`1.2rem`，行高 `1.2`）；常规主标题 `33.75px`（`0.6rem`）；香槟金眉标 `22.5px`（`0.4rem`）；暗灰正文 `16.875px`（`0.3rem`）；脚注 `11.25px`（`0.2rem`）。字重克制、层级分明。

## 4. 容器与装饰禁用令（Hard Don'ts）
- **严禁**给暗色卡片加亮蓝/亮绿/高饱和外描边——实测所有暗卡均使用 `#0F0F0F` 实底无描边，仅靠 `#000` 与 `#0F0F0F` 极微弱明度差分区；
- **严禁**把多组工程测试数据画成带密集格线的后台表格——参照 `section-23`（严苛测试卡）：6 项数据排成干净的 3×2 留白矩阵，**内部零分割线、零小方框**，纯靠香槟金大数字 + 纯白项目名 + 小字括号条件建立秩序；
- **严禁**对清晰特写的硬件接口强行乱拉粗折线和带框标签——参照 `section-10`（全 2.5G 网口屏）：用精准冷银斜聚光直接打亮端口，左侧纯文字说明，零引线反而更高级；
- **严禁**将自然光桌面实拍图硬切贴入 `#000000` 暗场（必须走 Layer 1 AI 统一暗场聚光重构 + Layer 2 原厂标签/丝印局部 `patch`）。

## 5. 套系节奏规则（多屏/多图连出）
- **全套锁死**：纯黑 `#000000` 画布、香槟金属渐变金点缀体系、`#0F0F0F` 无描边暗卡、统一的暗拉丝地面微反射与冷银边缘高光。
- **逐屏切换**：
  1. **纯黑暗场立柱首屏**（左字右机 + 极简权威奖项标）
  2. **香槟金分组暗色摄影 Bento 总览**
  3. **4 幕章节过场屏**（`1px` 细金边空心胶囊 `Speed` / `Disposition` / `Smart` / `Experience` + `67.5px` 超大白字 + 机身纹理暗场微距）
  4. **幕内强节奏交替**：双光轨速率浮卡 $\rightarrow$ 巨型 `20% ↑` 金属雕塑数字 $\rightarrow$ 暗场 PCB 芯片微距 $\rightarrow$ 背面端口斜聚光特写 $\rightarrow$ 烟熏玻璃 X 光天线透视 $\rightarrow$ 暗调客厅实景 $\rightarrow$ 3×2 无框香槟金严苛测试卡。

## 6. 跨界适用场景与行业专精挂载槽
- **推荐跨界场景**：**BMS 保护板、储能电源/逆变器、功率半导体/芯片模组、汽车电子、服务器/网络硬件、高端音频/精密工业仪器**——极适合把“硬核工业硬件卖点”做成国际旗舰级暗场黑金大片。
