## 1. 光影与材质语言（实样与开源规范交叉提取）
- **光源设定**：极净大面积顶部柔光箱（Overhead Diffused Softbox），几乎消除杂乱阴影，把视觉焦点 100% 集中到阳极氧化铝的锐利薄边、键盘键帽微距倒角与金属色泽过渡上。
- **背景与台面**：严格采用**两阶极简浅中性面**——纯白 `#FFFFFF` 与浅云灰 `#F5F5F7` 交替切换（卡片与正文区 **100% 零渐变**；仅 Hero 首屏允许一道极克制的机身呼应浅渐变，如 `linear-gradient(180deg, #D4EAF6, #F9F9F9 75%, #FFF)`）。
- **材质与实景节拍**：硬件微距（MagSafe、接口、厚度边）一律置于无影 `#F5F5F7` 洁净画框内；生活场景照采用自然柔和暖光实景，与纯白硬件卡形成冷暖呼吸反差。

## 2. 样本中的典型构图与留白用法（参考区间）
- **典型留白区间**：样本画面常保留 **`45%–55%`** 纯白/浅灰呼吸区；页面纵向区块间距宽裕（实测 `128px–160px`），营造“美术馆展陈”般的从容感。
- **核心技法——字彻底退到画框外（Copy-Outside-Frame）与纯无字硬件屏**：
  - 硬件工艺特写与尺寸对比（如 MagSafe 键盘微距、`13"`/`15"` 侧边薄度对比）放入 `28px` 圆角 `#F5F5F7` 画框，**画框内部完全不压说明文字（甚至 0 文字）**，仅在必要时放极简 2 词尺度锚点（`13" display`）；
  - 所有解释性文案统一推到圆角画框正下方干净白底上，图文分离、零互相干扰。
- **典型信息密度**：样本文字面积常控制在 **`≤ 18%`**；KPI 性能屏直接裸排 3 列核心倍数（`9.5x` / `4x` / `3.8x`），不画背景框或进度条。

## 3. 色彩与字体纪律（实测 CSS Token × `apple/DESIGN.md`）
- **色板结构**：
  - 中性底色与文字占 **`95%+`**：主画布 `#FFFFFF`、次级展台/卡片底 `#F5F5F7`、主文字深炭黑 `#1D1D1F`、次级灰字 `#6E6E73`、三级弱灰 `#86868B`；
  - 唯一功能高亮色：交互蓝 `#0071E3`（主胶囊按钮）、正文链接 `#0066CC`；偶在 Hero 主标用极克制的机身同色系渐变（如 `#022640 → #5786AB`）。
- **字体排布**（实测 `SF Pro Display` / `SF Pro Text` 体系）：
  - 章节大标题 `80px`（`lh 1.05`，**负字距 `-0.015em`**，字重 `600`）；Hero 主标 `64px`（`lh 1.09`）；常规 H3 `48px`（`lh 1.0835`，`-0.003em`）；正文稳锁 `17px`（`lh 1.47`，`-0.022em`）；
  - **标志性神技——句首加黑中灰散文（Bold Lead-In Prose）**：放弃“独立小标题 + 换行 + 正文”，改将段落第一句核心结论（如 **`Two perfectly portable sizes.`** / **`AI in the fast lane.`**）设为 `#1D1D1F` 半粗/粗体，紧接同一段落的其余说明全部降为 `#6E6E73` 中灰常规体，极大降低视觉碎片感。

## 4. 可单独借用的原子手法 vs. 整体复刻风格边界
- **可单独借用的原子手法（保留客户自有品牌色也可直接用）**：
  - **字退画框外（Copy-Outside-Frame）**：让硬件微距留在干净无字画框里，把说明统统推到画框外的干净底色上；
  - **句首加黑中灰散文（Bold Lead-In Prose）**：段落第一句核心结论用深色半粗体，紧接说明降为中灰常规体，省掉琐碎小标题；
  - **两阶浅中性无描边分区**：用 `#FFFFFF` 与 `#F5F5F7` 色差 + 大圆角替代 `1px` 边框；
  - **细竖线裸排 KPI**：用 `1px` 细竖线分隔标志与 3 列裸排超大倍数，不套小方盒。
- **整体复刻时的风格注意项（仅在完整追求 Apple 美术馆气质时参考）**：
  - 样本回避 `1px` 卡片外描边、渐变卡片底色与重投影，全站极少在硬件微距上拉密集引线箭头或塞带框小方盒；若实际任务需明确标出专业接口位点，可按需切入 `P-02` 标注骨架，无需因原样本无引线而牺牲买家理解。

## 5. 套系节奏规则（多屏/多图连出）
- **全套锁死**：`#FFFFFF` $\leftrightarrow$ `#F5F5F7` 两阶无描边 `28px` 圆角体系、`SF Pro` 负字距大标题 + 句首加黑中灰散文、严格“字退画框外”的硬件展陈纪律。
- **逐屏切换**：`大留白悬浮首屏` $\rightarrow$ `28px 圆角横滑亮点卡（纯白芯片卡 + 暖光生活卡交替）` $\rightarrow$ `无字/少字正交尺寸对比屏（框外配句首加黑散文）` $\rightarrow$ `零文字细节微距 + 配色圆点卡` $\rightarrow$ `1px 极细竖线 + 裸排超大倍数 KPI 屏`。

## 6. 跨界适用场景与行业专精挂载槽
- **推荐跨界场景**：轻薄消费电子、高端小家电、医疗/办公精密仪器、浅色极简箱包/家居硬件、以及任何希望彻底洗掉“电商促销贴片感”的品牌旗舰展示页。
- **行业专精挂载规则**：迁移至 B2B 工业硬件或电商详情页时，本风格很适合承担**前 3–4 屏的品牌形象定调、外观尺寸对比（`M-001`）与核心性能倍数证言**；若涉及密集接口定义或完整规格表，建议顺滑衔接 `P-06A` 近距查阅网格或标准单栏斑马纹表（`M-005`/`M-020`），不在定调主图内硬塞密集表格。
- **本地选图标准（`local/`）**：仅收裁除顶部导航栏的纯净展陈屏，重点保留“纯无字硬件微距”“框外句首加黑散文”“1px 竖线裸排 KPI”三类最具 Apple 辨识度的构图。
